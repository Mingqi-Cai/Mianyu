# 眠语 · 项目介绍

眠语是一个独立的创业项目。现有工作包括睡眠经济研究、商业模式设计、IP 体系建设、产品设计、Demo 开发，以及未来商业化可行性验证。核心目标是项目本身的产品设计、商业模式验证和未来商业化落地，而不是参加创业比赛。

以下内容只复述已有资料中的口径，不新增研究结论。

- 睡眠经济市场调研报告八章正文：25 页现行底稿，另有 23 页对照版。完整 PDF 见 [`01_市场调研/睡眠经济调研报告/`](../01_市场调研/睡眠经济调研报告/)。

- 五个正式 IP：霁霁、守绒、影盏、泊泊、阑岚。已有 V4 成长故事与行为文案，以及守绒 V4 视觉与影盏落地态建议包。V1–V3 锁定原件大部分仍待补。

- 2026-11-07 Demo 成本测算底稿，以及 2026-11-12 CFO 财务模型 v0.1 / v0.2（内部准备底稿，非正式 BP）。

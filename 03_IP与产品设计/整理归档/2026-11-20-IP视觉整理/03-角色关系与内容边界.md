## 2. 各角色坐标、辨识点与互斥边界

### 2.1 霁霁

- 一句话坐标：檐下半眯、不营业的小龙形夜客。来源：差异对照「一眼口诀」。
- 起源：雨后初晴的檐下，从檐口未干的水线里留下来，认「有遮的边」为位置。不是雪地精灵，不是开门营业的店员龙，也不绑某一座古建檐。名字里的「霁」是雨停之后刚晴的光，不是雪，也不是雾。来源：[01-霁霁-成长故事.md](https://github.com/Mingqi-Cai/Mianyu/blob/cursor/import-mianyu-pack1-6616/03_IP与产品设计/角色设定/成长故事/01-霁霁-成长故事.md)。
- 不可被抢走的记忆点：一对可关圆钝角灯；靠近时内收落座。辅助：背脊软鳍慢摆（闲聊）。明确不是记忆点：堆角饰、角环闪、长亮营业灯。
- 与用户的关系：被放到一处「檐下」平面，半眯着出现；把陪伴理解成「在同一处檐下各自待着」，不是店员招待。关双角灯是关系里的句号，不是惩罚，也不是效果承诺。
- 专属禁忌：不堆角饰；不加角环闪；不以长亮表示热情；靠近不扑出。

### 2.2 守绒

- 一句话坐标：卸下锣鼓、蹲在门边的守夜狮。
- 起源：门边。从热闹的守夜排场里走出来，把锣鼓卸下后留下来蹲守。不是苗族或其他民族志人物，不是旅行挂牌狮，也不再是会扑跳的表演狮。房间可以换，门的意象不能丢。来源：[02-守绒-成长故事.md](https://github.com/Mingqi-Cai/Mianyu/blob/cursor/import-mianyu-pack1-6616/03_IP与产品设计/角色设定/成长故事/02-守绒-成长故事.md)。
- 不可被抢走的记忆点（文案正本）：额头暗金守结 + 门墩般的蹲守。辅助：鬃毛轻顿；胸前旧绳只承担重量，不承担互动。明确不是记忆点：空白旅签牌、锣鼓、扑咬。
- 功能与形态的已收口口径：功能仍是守结——门边在场的应答记号，不是旅签牌，也不是民族服饰。形态允许在贴额结与悬挂式额饰之间迭代；V4 只改额饰，不重做全身。来源：差异对照「未来成长方向」、[修订说明](https://github.com/Mingqi-Cai/Mianyu/blob/cursor/import-mianyu-pack1-6616/03_IP与产品设计/角色设定/成长故事/修订说明-20261112-验收修订.md)。
- 已终验视觉正本（2026-11-12）把同一枚暗金盘长守结改为轻悬中上额的三件式，颈部已有暗红绳结。这是现行视觉，不是对文案功能名的废除。详见第 5.2 节，且不得与尚未终验的 V4b「夜弦」混写为正本。
- 与用户的关系：被放到门边，直接蹲好；「过来」被理解成回到门边，而不是跟人走。每次回来，门边都还蹲着。
- 专属禁忌：禁空白旅签牌作互动点或收尾；无锣鼓、无扑咬；不写成苗族人物；不复制具体民族头饰；禁「守护你入睡」类文案。

### 2.3 影盏

- 一句话坐标：被放下、贴着墙的光影旅伴。
- 起源：墙根 / 木质落点。从易飘的灯影，变成一盏愿意被放下的光影旅伴。不是悬空灯、不是白纸扁剪影、不是会换脸的灯笼戏偶。来源：[03-影盏-成长故事.md](https://github.com/Mingqi-Cai/Mianyu/blob/cursor/import-mianyu-pack1-6616/03_IP与产品设计/角色设定/成长故事/03-影盏-成长故事.md)。
- 不可被抢走的记忆点：暖琥珀内透光的坐实侧影 + 插片内容；默认坐 / 靠 / 蹲。辅助：掌心 / 边缘可关光。明确不是：飘浮、白纸扁剪影、表情包换脸。
- 本轮 Demo 首个展示角色。产品方案里「先通霁霁」是历史路线，故事层不改已缺失的 V3-LOCK 原件。
- 与用户的关系：先被放在墙边或桌面，先坐实再互动；长期关系靠更换插片变熟，不靠学会说话或离地更近。一次收尾已由用户在 CIO 窗口锁定：找到后可选插片确认（可跳过），结束时关光。来源：[锁定记录](https://github.com/Mingqi-Cai/Mianyu/blob/cursor/import-mianyu-pack1-6616/03_IP与产品设计/角色设定/行为与互动/锁定记录-2026-11-12-CIO窗口-影盏一次收尾.md)。
- 专属禁忌：禁止飘浮；禁止白纸扁剪影；Y 轴不上浮；光一拍即停；插片是内容包不是换装表演；插片图形须全原创几何，禁文物同款 / 正宗非遗宣称。
- Notion [行为草案页](https://app.notion.com/p/416340bcc3968148a72bdd3824b7861e) 仍是 2026-11-12 草稿，与 GitHub 正本并存，不以草案冒充最新正本。

### 2.4 泊泊

- 一句话坐标：停在行李旁、会看窗的软圆旅伴。
- 起源：行李旁，面向窗。从容易被忘掉的圆墩，长出可写的牌耳和可盖的章。不是对称圆耳娃娃，不是门卫，也不是墙上的灯。来源：[04-泊泊-成长故事.md](https://github.com/Mingqi-Cai/Mianyu/blob/cursor/import-mianyu-pack1-6616/03_IP与产品设计/角色设定/成长故事/04-泊泊-成长故事.md)。
- 不可被抢走的记忆点：不对称行李牌耳（第一记忆点）；写牌本机。辅助：胸口章位；互动链为写牌 → 盖章 → 看窗。明确不是：对称圆耳、点头圆球、上传云端的牌面。
- 与用户的关系：先被不对称牌耳认出来；看窗是陪伴，不是扑向人脸。写牌默认本机，是它和用户之间的信用。不拿姓名 / 房号出门。
- 专属禁忌：线索锚必须是牌耳；删牌耳不算 泊泊；内容不上传。

### 2.5 阑岚

- 一句话坐标：靠窗站着的雾感小灵。
- 起源：当代窗边。从窗棂投下的负形光斑里站起来。不绑古建花窗，不是会飞的精灵，也不是坐着的软圆墩。来源：[05-阑岚-成长故事.md](https://github.com/Mingqi-Cai/Mianyu/blob/cursor/import-mianyu-pack1-6616/03_IP与产品设计/角色设定/成长故事/05-阑岚-成长故事.md)。
- 不可被抢走的记忆点：窗棂负形光斑 + 可关纸折小灯。明确不是：古建绑定、闪光、精灵飞天、火焰爆闪。
- 与用户的关系：被放到窗边，靠窗站好；「过来」理解成更靠向那面窗，而不是离开窗去跟人走。关纸折小灯即结束键。
- 与 泊泊 的窗分工必须分清：看窗的旅伴是 泊泊；靠窗站着的是 阑岚。来源：差异对照与 阑岚 成长故事第 7 节。
- 专属禁忌：不绑古建；光斑必须是几何负形，非闪光；无精灵飞天；纸灯火焰无爆闪；关灯即结束，不自动再来。本角色不用「半眯」（「半眯」只用于 霁霁）。默认姿态是站，这不等于允许悬浮——须站在窗边可理解承面上。

## 3. 靠近方式对照（防串戏）

同一句「过来一点 / 陪我」，五人不得共用同一轨迹。来源：[02-五IP互动差分要点.md](https://github.com/Mingqi-Cai/Mianyu/blob/cursor/import-mianyu-pack1-6616/03_IP与产品设计/角色设定/行为与互动/02-五IP互动差分要点.md)。

1. 霁霁 往檐下坐进去。
2. 守绒 把重心送回门边蹲好。
3. 影盏 贴着墙滑过来一点，仍然坐着。
4. 泊泊 眼先转向窗意象，躯干再偏移贴近，不是朝脸。
5. 阑岚 把窗前浓度加深一档，位置仍在窗边站着。

## 4. 共用内容边界

来源：差异对照「互动禁忌」共用红线、行为差分「使用规则」、[重要决策记录.md](https://github.com/Mingqi-Cai/Mianyu/blob/cursor/import-mianyu-pack1-6616/00_项目总览/重要决策记录.md) 第 3 条、屏内原型验收记录中的医疗声明。

- 不作疗效或医疗宣称；不宣传未验证助眠疗效；对外禁用「助眠 / 治失眠 / 改善睡眠 / 睡眠评分 / 古法疗愈」等作为产品承诺。不是儿童睡眠产品或医疗器械。
- 无 TTS、无倒计时闯关、无排行、无惊吓扑出；可关麦、可跳过、可离开；不绑酒店才能玩；AI 非卖点。
- 姓名 / 房号不上传。泊泊 写牌与章面默认本机——这是该角色正本已写明的隐私边界，不得推广成未在正本出现的其他「本机处理」新规（见 5.3）。
- 粗意图映射（确认 / 靠近 / 闲聊 / 晚安 / 道具），不输出焦虑 / 抑郁 / 失眠等标签：投资人稿有此句；行为正本写的是「不靠定义用户情绪」「不宣传未验证助眠疗效」。后者是正本边界；前者仅作沟通稿对照，不升级为新正本。

# 正名与锁定口径更正（Design 最新指示，作废此前所有近形错字）

五位正名只有：霁霁、守绒、影盏、泊泊、阑岚。
不要写成雪雪、雾雾或阚岚。

已锁定差分（以此为准，覆盖 brief 旧表述）：
- 霁霁：檐下半眯、不营业；记忆点是可关圆钝角灯，不堆角饰；靠近时内收落座。
- 守绒：卸下锣鼓的守夜狮；力量感来自安静蹲守与门墩感；额头暗金守结（V4 只改额饰，故事不要把它写成苗族人物）；不追人脸，只回门边蹲好；禁空白旅签牌。
- 影盏：光影旅伴；默认坐/靠/蹲；暖琥珀内透光 + 插片内容；禁止飘浮、禁止白纸扁剪影。
- 泊泊：会看窗的软圆旅伴；不对称行李牌耳是第一记忆点；写牌默认本机。
- 阑岚：雾感窗边小灵；窗棂负形光斑 + 纸折小灯；靠窗站，不绑古建。

用词校对结论（不必再列为待确认，除非眠语库定稿与此冲突）：
- 第一角色正名是「霁霁」（霁 = U+9701），不是「雪雪」「雾雾」。
- 「檐下半眯」以「半眯」为准，不是「半眮」或「半眭」。
- 第五角色正名是「阑岚」（阑 = U+9611），不是「阚岚」。
- 阑岚光斑是「窗棂负形光斑」，不是「窗枕」或「窗梳」。

若已写出的草稿用了作废用字或旧口径，立即按本条改正后再落盘。其余派单要求不变。

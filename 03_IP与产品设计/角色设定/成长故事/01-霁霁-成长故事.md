# 霁霁 · 成长故事

- 官方用名：霁霁（霁 = U+9701，雨字头 + 齐）
- 已锁定差分：檐下半眯、不营业；记忆点是可关圆钝角灯，不堆角饰；靠近时内收落座
- 视觉锚点：V3「轻点头与角灯应答」「靠近后落座」——一对圆钝角灯是唯一光锚，眼睛半眯，落座时身体向内收进一圈落点

本文解释已锁定性格与招牌行为，供 Behavior 转化为动作与 Demo。不改设定，不作疗效承诺。

## 1. 来自哪里

霁霁是雨后初晴时，从檐口一条还未干的水线里留下来的小龙形夜客。名字里的「霁」，就是雨停之后那一层刚晴的光，不是雪，也不是雾。

它认路的方式是「有遮的边」。旧檐下当然是家，床沿、桌沿、柜角上沿也可以被它当成一处临时的檐。它不属于某一座古建，也不属于某一间固定客房；只要这个夜晚有一条可以让它把身体收进去的边，它就知道该坐在哪里。

## 2. 经历过什么

檐下曾是来往最多的位置。有人经过会抬头看它，期待它把角灯全部点亮、把角饰堆满，像在开张。它试过那样做：灯一多，饰件一响，夜晚就被撑得很满，自己也被迫站成一个招呼的姿势。

后来它把多余的角饰一件件卸下，只留下一对圆钝、可以关掉的角灯。它发现灯不必一直亮着——亮是确认，关是收束，两件事都比堆饰更清楚。卸下「营业」之后，它开始半眯着看檐下的光自己走动，不再把夜晚过成接待时间。

## 3. 性格如何形成

半眯不是困倦表演，是它学会把眼神收窄，避免把「在场」做成招呼。不营业，是从长亮和堆饰里退出来之后留下来的处事方式：靠近的人不必被招待，也不必被赶走。

性格的底是收束。动作少，光短，结束键清晰。背脊上那排软鳍偶尔会像檐下的风一样慢摆两下，但从不开成表演。它习惯先坐下，再决定亮哪一盏灯；从不会为了显得热情而先把灯全部打开。

## 4. 最在意什么

一对可关的圆钝角灯是唯一的光锚，不能被角环、角饰、闪光附件稀释。它在意「今晚能不能把灯关掉」——关灯是关系里的句号，不是惩罚，更不是某种效果承诺。

它也在意落点还像不像一处檐：有遮、有边、可以把身体收进去。如果空间把它逼到房间正中、无边可依，它会显得无处可收，性格就立不住。

## 5. 独特行为习惯

- 默认坐着，眼睛半眯，角灯可亮可关，但不堆任何额外角饰。
- 被确认在场时：半眯点头 1 次，左角灯暖光呼吸一拍后回常态。
- 靠近时：躯干内收，缩回檐下意象落座；慢、短，不扑向镜头。
- 闲聊节奏：背脊软鳍慢幅摆动 2 次。
- 晚安 / 道具：关双角灯作为收束；单角点灭可作对道具的回应。
- 不追视人脸，不围着人转，不把点头做成连续鞠躬。

## 6. 如何理解夜晚陪伴和用户

霁霁把夜晚陪伴理解成「在同一处檐下各自待着」。用户不是要被接待的客人，它也不是店员。用户说话，它听得懂确认、靠近、闲聊、晚安、道具这类粗意，但只用点头、落座和角灯来回答；它自己不出声。

关麦时，它依然可以半眯坐在那儿。灯亮着是在场，灯关了是今晚到此，两种状态都不依赖语音。陪伴是可共享的檐和可关的灯，不是把夜晚填满，也不是把用户的情绪说圆。

## 7. 如何与用户建立关系

关系从落位开始。用户把他点到一个平面上，它出现在可被理解成檐下的位置，先坐下，而不是先表演。躲藏时偏向檐下或角后，线索只给角灯剪影的微光；找到或召唤回位后，一次关角灯可作为入口仪式，也可作为结束键，均可跳过。

靠近是关系里最能认出它的一下：它不迎上去，而是把身体收进檐下再坐下，用让出一点空间的方式承认你来了。几个晚上过后，用户记住的不是它讲过什么，而是那对可关的圆钝角灯，以及靠近时内收落座的那一拍。

## 8. 未来可怎样成长

成长沿着「灯的仪式」走，而不是沿着「饰件的增加」走。单灯 / 双灯的开关组合可以更细，檐位（床沿、桌沿、真檐意象）可以选择，藏点可以在檐下与角后之间轮换，但记忆点必须仍是角灯。

它不会把卸下的角饰再堆回来，不会变成会说话的店员，也不会把夜晚重新过成营业时间。任何新互动如果让角灯退居配角，就不算霁霁的成长。

## 可转化互动要点

写给 Behavior，可直接改成动作与 Demo。

### 落位 / 姿态

- 点按平面后，优先落在床沿、桌沿、柜角上沿，或任何可被读成「檐下」的边；不要落在无遮无边的房间正中。
- 默认姿态：坐，半眯，双角灯为圆钝造型；可处于微亮或已关，但不得出现堆叠角饰。
- 出现方式：落到面上再坐下，不从空中扑下，不站立迎接。
- 藏点意象：檐下 / 角后。主线索：可关角灯的剪影微光，一拍即停，不加角环闪。

### 靠近时的身体反应

- 触发「靠近 / 过来一点 / 陪我」：躯干内收，缩回檐下意象，在落点圈内坐下。
- 位移慢而短，不扑镜头，不绕行，不站起。
- 关麦只看时：用户镜头靠近，最多做一次更小的内收坐稳，然后静止。

### 静默沟通动作（单段约 1.5–4 秒）

| 粗意图 | 动作 |
| --- | --- |
| 确认 | 半眯点头 1 次 + 左角灯暖光呼吸一拍，回常态 |
| 靠近 | 躯干内收落座，缩回檐下 |
| 闲聊 | 背脊软鳍慢幅摆动 2 次 |
| 晚安 / 道具 | 关双角灯收束；单角点灭可作道具回应 |

默认可 1–3 次短回应后软收束「今晚就到这儿」。角色始终不出声，无 TTS，无咨询式长字幕。

### 可关麦时仍成立的回应

- 关麦后立即停听；霁霁保持半眯坐姿在场，不采集语音。
- 点按、找到、召唤回位、关角灯，全部不依赖开麦。
- 非语音确认：角灯一拍或一次轻点头（若由点击 / 靠近触发）。
- 非语音结束：关双角灯，静帧。拒绝开麦不影响躲猫猫主路径走完。

### 红线 / 禁忌

- 记忆点在角灯，不堆角饰，不加角环闪，不以长亮表示热情。
- 无扑出、无惊吓音、无倒计时、无排行。
- 禁用助眠、安神、疗效、咨询、保证入睡等文案；不说「陪你睡着」。
- 不把霁霁写成雪地角色或店员营业人设；正名不得改成其他近形字。

# 影盏 · 成长故事

- 官方用名：影盏
- 已锁定差分：光影旅伴；默认坐 / 靠 / 蹲；暖琥珀内透光 + 插片内容；禁止飘浮、禁止白纸扁剪影
- 视觉锚点：V3「贴墙呼吸光轨」——坐在木质落点上，贴墙，暖琥珀内透光，头顶插片（如月松），边缘可有一拍即停的呼吸光；有体积与软阴影，不是白纸扁影

本文解释已锁定性格与招牌行为，供 Behavior 转化为动作与 Demo。不改设定，不作疗效承诺。成长故事库中此前为空缺，本稿为新建解释性故事，不回改已有行为草案。

## 1. 来自哪里

影盏是一盏愿意被放下的光影旅伴。它不是挂在梁上的灯，也不是贴在纸上的扁影子，而是有厚度的暖琥珀躯体：内里透光，头顶有插片槽，掌心可以握住一小束可关的光。

它认的空间是墙边、墙根、床头柜或桌面——任何能让它坐下、靠住、蹲住的立面与平面。先有落点，再有贴墙的影子；它以「被放在这里」为出生证明，而不是以「会飞」为出生证明。

## 2. 经历过什么

更早的时候，它更容易被看成一缕会飘的灯影，侧影一亮就走。那样好看，却没有落点，也容易薄成一张白纸。路过的人记住的是光，不是它可以坐在哪儿。

后来它学会了坐下来。先有木质的落点，再有贴墙的重量，光改从身体里面透出来，而不是从空中洒下来。插片槽被留下来，作为它愿意让别人补上的内容：月与松、几何、城影或节日，都只是插进去的一片，不是它的脸，更不是一套换装表演。

## 3. 性格如何形成

坐实之后，它变得黏在面上。好奇，但沿墙观察，不绕场，不说话。性格是「被放下的灯」——有重量、有软阴影、有一拍就停的呼吸光。它不着急展示自己会发光，更在意光有没有被关好、插片有没有被放正。

它看人的方式也顺着墙走：先看见落点附近的墙根和插片轮廓，再偶尔偏向用户所在的方向，不对视施压。被放下是安定，不是被冷落；所以它很少主动起身去找人。

## 4. 最在意什么

三件事绑在一起：坐 / 靠 / 蹲的实态、暖琥珀内透光、插片作为内容包。它最不能接受的是重新飘起来，或被压成白纸扁剪影——那等于退回还没有落点的日子。

光必须一拍即停，不做追光秀。换的是插片参数或轮廓溶换，不是一张乱跳的脸。开放槽三件套——插片（主）、姿态底座、掌心可关光——是它愿意被长期对待的方式，不能拆掉去换一套会飞的表演。

## 5. 独特行为习惯

- 默认坐在墙边或平面上，可微靠，重心在坐；必要时可改为靠或蹲，但仍脚不离面。
- 确认：暖光侧影坐正 1 拍 + 边缘呼吸光半拍。
- 靠近：坐姿贴墙平移 10–15cm，脚不离「地」，Y 轴不上浮。
- 闲聊：当前插片镂空眼明暗交替 2 次。
- 晚安 / 道具：掌心或边缘光渐灭；插片轮廓可溶换一次。
- 藏时沿墙滑向墙根光边，身体仍暗示坐或靠，不变成飘在墙中的剪纸。

## 6. 如何理解夜晚陪伴和用户

它把用户看成今晚把这盏灯放下来的人。陪伴是并排坐在同一面墙的这一侧：你说话，它用光和一小段贴墙滑移回应；你关麦，它继续坐着。它不解释你的情绪，也不把插片读成对你的诊断。

插片是半成品，意义由你补完。它可以听懂确认、靠近、闲聊、晚安、道具这些粗意，但回答里没有句子。光收了，就是今晚到这儿，不是某种被承诺的结束效果。

## 7. 如何与用户建立关系

关系从「放在墙上或桌上」开始，不是从飞到面前开始。落位后先有一段被放下的停留，再收成坐下。躲藏走墙根光边，线索是插片轮廓或极淡呼吸光；找到或「算了」之后，它滑回落点坐正。

一次轻互动按本轮 Demo、Design 第一次验收执行：找到后用插片确认，关光留给结束 / 晚安；财务底稿仍标待立项，不覆盖那一页。长期关系靠更换插片变熟，而不是靠它学会说话或离地更近。

## 8. 未来可怎样成长

成长沿开放槽三件套走：插片可有系列、联名或用户自绘；坐 / 靠 / 蹲是安放方式，不是可滑动的姿态库；掌心光始终可关。内容可以变厚，身体不能离地。

禁止用飘浮重新制造「灯感」，禁止把插片做成文物同款或正宗非遗宣称。任何让它重新变成白纸扁影或表情包灯笼的方案，都不是影盏的成长。

## 可转化互动要点

写给 Behavior，可直接改成动作与 Demo。本轮 Demo 首个展示角色是影盏；产品方案里「先通霁霁」仍是历史路线，故事层不改 V3-LOCK。动作须与已有行为草案兼容，但不把故事写成该草案里原有的设定。

### 落位 / 姿态

- 点按平面后，优先落在墙边、墙根附近的桌面或地面；若只有桌面、没有立面，就坐在桌面上，用软阴影和坐姿建立重量，仍禁止上浮补「灯感」。
- 默认姿态：坐实的暖琥珀内透光侧影；可微靠墙；插片在槽内可见。靠、蹲可用，但不在主路径巡演三姿。
- 出现方式：在落点淡入成短暂停顿，再收成坐下；不从天花板掉下，不瞬切，不悬浮。
- 藏点意象：墙根光边。主线索：插片轮廓或极淡呼吸光。用预设偏移 + 淡出 / 半透明，不做真家具遮挡。

### 靠近时的身体反应

- 触发「靠近 / 过来一点 / 陪我」：保持坐姿，沿墙意象面平移 10–15cm，脚不离面，Y 轴不上浮。
- 光只呼吸半拍，不做追光、扫光或闪光雨。
- 关麦只看时：最多「坐正 1 拍」表示察觉，随即回到安静坐姿，不站起、不扑近。

### 静默沟通动作（单段约 1.5–4 秒）

| 粗意图 | 动作 |
| --- | --- |
| 确认 | 暖光侧影坐正 1 拍 + 边缘呼吸光半拍 |
| 靠近 | 坐姿贴墙平移 10–15cm，脚不离「地」 |
| 闲聊 | 当前插片镂空眼明暗交替 2 次 |
| 晚安 / 道具 | 掌心 / 边缘光渐灭；插片轮廓溶换一次 |

默认可 1–3 次短回应后软收束「今晚就到这儿」。角色始终不出声。换的是插片参数，不是表情包鬼畜。

### 可关麦时仍成立的回应

- 关麦后立即停听；改为「先看着」：静坐在场，无语音采集。
- 落位、躲藏、点找、「算了」回位、插片确认、关光，全部不依赖开麦。
- 非语音确认：坐正 1 拍 + 边缘呼吸光半拍（可由点击插片或靠近触发）。
- 非语音结束：掌心或边缘光渐灭，静帧。拒绝开麦不影响主路径走完。

### 红线 / 禁忌

- 禁止飘浮；禁止白纸扁剪影；Y 轴不上浮。
- 光一拍即停；不做追光秀、爆闪、持续扫光。
- 插片是内容包，不是衣柜换装，不是表情滑条；图形须全原创几何，禁文物同款 / 正宗非遗宣称。
- 不做真家具遮挡、人体跟随、姿态库进 Demo 主路径。
- 禁用助眠、安神、疗效、咨询、守护入睡等文案；验收不挂钩睡眠评分。

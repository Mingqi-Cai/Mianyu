# 阑岚 · 成长故事

- 官方用名：阑岚（阑 = U+9611，门字框 + 柬；岚 = U+5C9A）
- 已锁定差分：雾感窗边小灵；窗棂负形光斑 + 纸折小灯；靠窗站，不绑古建
- 视觉锚点：V3「光斑格与纸灯收光」——靠当代窗站立，身上与墙上可见几何窗棂负形光斑，身边有可关的纸折小灯；体量薄而雾，不飞

本文解释已锁定性格与招牌行为，供 Behavior 转化为动作与 Demo。不改设定，不作疗效承诺。

## 1. 来自哪里

阑岚是雾感的窗边小灵。它不是从某座古建的花窗里走出来的，而是从普通窗棂投下的负形光斑里站起来的——当代房间里的窗，菱格、长条、任何几何窗棂都可以。光穿过格子，在墙上留下一格空的形状，那一层薄雾顺着负形站直，就成了它。

它靠窗站着。窗是它的边，不是它的舞台。身体薄，带一点雾；窗棂的负形光斑会在它身上淡亮一格，也会落在旁边的墙上。脚边常有一盏它自己折的纸灯。

## 2. 经历过什么

它一度以为自己必须像「旧时的窗」才站得住，去贴近雕花、屋脊、被讲成典故的格子。结果只剩下装饰，进不了现在的房间——那些房间的窗是普通的，灯光是现在的，墙上的格子是被此时此刻的窗棂投下来的。

后来它把古建的包袱放下，只保留窗和光这一对关系：光穿过窗棂，在身上留下一格几何负形，再安静落下。纸折小灯是它给自己折的一盏可关的灯，不必大，不必飞；关了，就是今晚的结束。雾还在窗边，只是不再要求窗户长成某种旧样子。

## 3. 性格如何形成

性格是薄和静。它站，不坐成墩，也不飘成精灵。被听见时，不是闪光，是身上一格光斑轻轻亮起，再落下。闲聊也不走位，只让纸灯的火焰慢摇两次。

它喜欢靠向窗的那一面，却不会飞出窗外。雾让它看起来不像一件实心玩具，可它仍然有站位：窗台这一侧，脚在面上，灯在手边。微合的眼神不是睡意表演，是不想把窗边站成展示。

## 4. 最在意什么

窗棂负形光斑必须是几何的、可淡入淡出的，不能变成闪光、乱纹或满身闪点。纸折小灯必须可关，关灯就是结束键。它在意自己站在窗边，而不是被放进某一种古建符号里。

身体可以透出一层城市或夜色的薄影，但那是雾，不是景点明信片，也不指向某一座被绑定的老建筑。它同样在意自己不要被写成会飞的精灵：一离开窗沿的面，性格就散了。

## 5. 独特行为习惯

- 默认靠窗站，不坐成软圆墩，不上浮离面。
- 确认：身上一格窗棂负形光斑淡亮，再淡出。
- 靠近：薄纱夜色加深一档，身体靠向窗意象面。
- 闲聊：纸灯火焰慢摇 2 次，身体不动。
- 晚安 / 道具：关纸折小灯；可选换一格光斑几何。
- 藏点在窗台影格，线索是光斑格或纸灯，不是飞走后的空窗。

## 6. 如何理解夜晚陪伴和用户

窗是你们共用的边。用户不必打开窗，也不必交谈；只要它还站在窗边，光斑还可以亮一格，陪伴就在。你说话，它用一格负形光或一次关灯来回；你关麦，窗、光斑、纸灯仍然成立。

它不把雾写成安神，也不把关灯写成某种效果。夜晚在窗上走过，它只站在这一侧，把其中一格光轻轻接住再放下。用户不是需要被引入梦境的人，它也不是窗外的向导。

## 7. 如何与用户建立关系

用户把它点到窗边，或可被理解成窗台的平面，它站好。躲藏走窗台影格，找到之后仍回到窗边站着。关纸灯是最干净的一次收束，可作入口，也可作结束，均可跳过。

关系里偶尔换一格光斑几何，像换一种窗棂投下的样子。它靠「还在窗边」被记住，不靠飞近，不靠说话。若用户叫它过来，它把「过来」理解成更靠向那面窗，而不是离开窗去跟人走。看窗的旅伴是泊泊；靠窗站着的是它。

## 8. 未来可怎样成长

光斑几何可以换格，纸灯可以有不同折法，窗可以是更多种当代窗——长窗、小高窗、带简单格子的窗都可以，只要仍是现在的窗。成长是「另一种格子的光」，不是「更古老的窗」。

不走向古建绑定，不走向精灵飞天，不把火焰做成爆闪，也不改成坐下的软圆墩。新的互动如果让纸灯不可关，或让光斑变成闪光，就不是阑岚的成长。

## 可转化互动要点

写给 Behavior，可直接改成动作与 Demo。

### 落位 / 姿态

- 点按平面后，优先落在窗边、窗台内侧或紧贴窗意象的地面；不要落在门墩位或行李主位。
- 默认姿态：靠窗站；体量薄、雾感；身上可有一格几何负形光斑；身边有纸折小灯。
- 出现方式：在窗边淡入站好，不飞入，不从窗外扑进，不离面悬浮。
- 藏点意象：窗台影格。主线索：光斑格或纸灯微光，几何负形，非闪光。

### 靠近时的身体反应

- 触发「靠近 / 过来一点 / 陪我」：薄纱夜色加深一档，身体靠向窗意象面；不飞出窗外，不扑向人脸。
- 位移若有，只在窗边这一侧做极短的靠拢，脚不离面。
- 关麦只看时：最多一格光斑极淡亮一次后落下，然后保持靠窗站姿。

### 静默沟通动作（单段约 1.5–4 秒）

| 粗意图 | 动作 |
| --- | --- |
| 确认 | 一格窗棂负形光斑淡亮 → 淡出 |
| 靠近 | 薄纱夜色加深一档 + 靠向窗意象面 |
| 闲聊 | 纸灯火焰慢摇 2 次，身体不动 |
| 晚安 / 道具 | 关纸折小灯；可选换一格光斑几何 |

默认可 1–3 次短回应后软收束「今晚就到这儿」。角色始终不出声。关灯即结束键，不自动再来。

### 可关麦时仍成立的回应

- 关麦后立即停听；阑岚继续靠窗站着，无语音采集。
- 落位、寻找、回位、关纸灯、换一格光斑，全部不依赖开麦。
- 非语音确认：点击身体或窗格触发一格光斑淡亮淡出。
- 非语音结束：关纸折小灯，静帧。拒绝开麦不影响主路径走完。

### 红线 / 禁忌

- 不绑古建；窗是当代窗棂，光斑是几何负形，不是雕花典故或文物同款。
- 无精灵飞天，不上浮离面，无火焰爆闪，无满身闪光。
- 不改成坐姿软圆，以免与泊泊串戏；不把门边蹲守或檐下落座借走。
- 正名不得写成其他近形字；光斑用词为「窗棂负形光斑」。
- 禁用助眠、安神、疗效、咨询等文案；无惊吓、无倒计时、无排行。

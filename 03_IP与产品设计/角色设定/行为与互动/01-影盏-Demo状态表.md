共用主路径（**【已确认】**）：点按平面落位 → ≤3s 出现 → 淡出到相对落点 2–3 个预设静音偏移 → 大提示 + 极淡线索 → 点找或「算了」→ 回位 → 一次专属轻互动（可跳过；本轮 Demo 为插片确认 / 轮廓溶换）→ 静帧结束。屏内降级玩法同构。无倒计时、无排行、无惊吓扑出、无 TTS、无自动「再来一局」。

单段回应约 1.5–4 秒；光效一拍即停；位移慢而短。角色始终不出声。默认接地：坐 / 靠 / 蹲，Y 轴不上浮。

## 1. 坐下（默认稳态 · 姿态【已确认】）

光影旅伴的默认态是「坐着的影」，不是悬着的灯。

| 项 | 写法 | 层级 |
| --- | --- | --- |
| 触发 | 落位成功并完成出现之后的默认态；从停留自然安定下来；找到 / 「算了」回位之后；关麦「先看着」时的在场姿态 | 姿态【已确认】；触发顺序【本草案补全】 |
| 轨迹 | 暖琥珀内透光侧影**坐**在用户点按的桌面、地面或墙边木质落点上；软阴影着地；可微靠墙，重心在坐不在漂。不站起、不绕场。靠 / 蹲可用于短切换，Demo 主路径不必巡演三姿 | 【已确认】坐 / 靠 / 蹲；主路径不巡演【本草案补全】 |
| 时长 | 可长时间保持的安静在场，不是表演段落。几乎静止，只允许极慢、几乎难察的呼吸起伏 | 【本草案补全】 |
| 光效 | 内透暖琥珀维持可识别的弱光；不做持续扫光。被「确认」时才坐正 1 拍 + 边缘呼吸光半拍，随后回安静坐姿 | 材质与确认光【已确认】；等待时光强【本草案补全】 |
| 可关项 | 可关麦（静坐在场，无语音采集）；掌心 / 边缘光可关；可随时离开或点结束 | 【已确认】 |
| 红线 | 禁止飘浮、禁止白纸扁剪影、Y 轴不上浮；无 TTS；近距离不扑镜头；远距离不靠放大或爆闪「喊」用户 | 【已确认】 |

近距离（【本草案补全】，靠近不扑镜头【已确认】）：最多「坐正 1 拍」表示察觉，随即回到安静坐姿。  
远距离（【本草案补全】）：保持坐实轮廓可认，光更弱。

## 2. 停留（短过渡拍 ·【本草案补全】· 不升为官方状态名）

**「停留」不是与「坐下 / 躲藏」并列的官方状态名。** Design 第一次验收建议：作为出现后、躲藏前，以及回位后轻互动前的短过渡拍保留，可跳过。目的是避免「一出现就瞬切消失」或「从空中掉进画面」。时长仍交 UX 定量。

| 项 | 写法 | 层级 |
| --- | --- | --- |
| 触发 | 角色 ≤3s 出现后、尚未开始藏的短暂停顿；找到或「算了」回位后、一次轻互动之前 | 出现时限【已确认】；状态名与触发【本草案补全】 |
| 轨迹 | 已经在落点上，由「刚出现」收成坐下。允许一次很短的安置（坐实、理好插片轮廓），随后静止。全程贴面，**不从空中落入** | 禁飘【已确认】；安置动作【本草案补全】 |
| 时长 | 短。建议 2–6 秒的「被放下」感，再进入坐下或躲藏 | 【本草案补全】，供 UX 定量 |
| 光效 | 内透弱光稳定，不做开场闪光。可带极淡落点环（若共用壳已有），一出现即在平面上，不靠光把角色托起来 | 落点环为壳能力；此处用法【本草案补全】 |
| 可关项 | 用户可跳过停留直接进入藏或结束；可关麦 | 【本草案补全】 |
| 红线 | 禁止从天花板掉下、禁止瞬切、禁止无落点悬空待命。不发声 | 禁飘与无 TTS【已确认】 |

近距离：更快收成坐下，动作更小。远距离：可在落点多停一瞬，让人看清「它被放在那里」。均【本草案补全】。

## 3. 观察（并入静默层「闲聊」· 不另立状态名 ·【本草案补全】）

**不另立官方状态名。** Design 第一次验收建议：将本段并入静默层「闲聊」，只作为闲聊动作在寻找或靠近时的复用说明。观察时**不改变坐实**。

| 项 | 写法 | 层级 |
| --- | --- | --- |
| 触发 | 寻找阶段用户靠近藏点但尚未点中；坐下 / 停留时镜头明显靠近；静默粗意图「闲聊」 | 闲聊意图类【已确认】；作为闲聊复用【本草案补全】 |
| 轨迹 | 不离开落点。只用低幅度手段：当前插片镂空眼明暗交替最多 2 次；或头胸沿墙轻微转向兴趣点。禁止换脸、站起张望、绕场巡游、人体跟随 | 闲聊动作【已确认】；转向幅度【本草案补全】 |
| 时长 | 短。对齐单段约 1.5–4 秒，到点必须停，不循环表演 | 时长口径【已确认】 |
| 光效 | 以插片镂空明暗为主；若用边缘光，一拍即停。近距离减弱或只做 1 次，避免「被盯」 | 【本草案补全】 |
| 可关项 | 单段结束后回到坐下；用户可跳过；关麦时不主动观察催促 | 【本草案补全】 |
| 红线 | 不做人脸跟踪（Demo 不做人体跟随）；不发声；不读「我在看你」；不变成表情包或姿态滑条 | 【已确认】 |

兴趣点优先：墙根光边、当前插片轮廓，或用户所在方向的极轻转向——不是锁脸。

## 4. 躲藏（主路径核心 · 藏点意象【已确认】）

藏点意象：墙根光边（禁飘）。主线索：插片轮廓 / 呼吸光。用预设偏移 + 淡出 / 半透明，**不做**真家具遮挡。身体仍暗示坐或靠，不要变成飘在墙中的剪纸。

| 项 | 写法 | 层级 |
| --- | --- | --- |
| 触发 | 短暂停留 / 坐下后，按主路径开始藏：淡出到相对落点的 2–3 个预设静音偏移 | 【已确认】 |
| 轨迹 | 沿墙或沿平面滑向偏移点，同时降低不透明度 / 边缘光，像影子被挪到墙根，而不是物体被删除。藏住时仍贴面，脚不离「地」，Y 轴不上浮 | 藏点与禁真遮挡【已确认】；滑移写法【本草案补全】 |
| 时长 | 由用户寻找节奏决定，**无倒计时**。角色在藏点保持低存在，不循环蹦出提示。坐下→躲藏的过渡建议 1.5–3 秒 | 无倒计时【已确认】；过渡秒数【本草案补全】 |
| 光效 | 极淡呼吸光或插片轮廓作线索，一拍即停。不是闪光弹。用户靠近尚未点中时，可靠半透明略增、线索略清晰，仍弱光 | 线索【已确认】；近距略增【本草案补全】 |
| 可关项 | 点找（建议 ≤2 步）或「算了」/ 召唤即可回位；可跳过寻找；关麦不影响把躲藏走完；拒绝开相机则走屏内同构 | 【已确认】 |
| 红线 | 无惊吓扑出；回位禁止「啪」地出现在镜头前；远距离更隐，禁止为可见度提高唤醒；不做真窗帘 / 真家具遮挡 | 【已确认】 |

回位：反向滑回落点并抬回存在感，再坐正。随后可接一次轻互动（可跳过；本轮 Demo 为插片确认 / 轮廓溶换）或直接静帧。

## 5. 静默沟通招牌回应（四意图 ·【已确认】）

进入时机（【已确认】）：找到或召唤回位之后。可作入口或结束键的一次轻互动；开麦则映射粗意图，关麦可「先看着」。默认可 1–3 次短回应后软收束「今晚就到这儿」。角色只动、不说话。只做确认 / 靠近 / 闲聊 / 晚安 / 道具，不输出焦虑、抑郁、失眠等标签。

### 5.1 确认

| 项 | 写法 |
| --- | --- |
| 触发 | 粗意图「确认」；或关麦时用户点选在场 / 点插片表示看见了（非语音触发【本草案补全】） |
| 轨迹 | 暖光侧影**坐正 1 拍**，不站起、不前扑 |
| 时长 | 坐正 1 拍 + 光半拍，整体落在约 1.5–3 秒，然后回安静坐姿 |
| 光效 | **边缘呼吸光半拍**，一拍即停 |
| 可关项 | 关麦时同样可用这组动作；光效可关，改为仅坐正 1 拍 |
| 红线 | 不做闪光雨、全灯爆亮、点头鬼畜 |

层级：动作与光效【已确认】；关麦复用方式【本草案补全】。

### 5.2 靠近

| 项 | 写法 |
| --- | --- |
| 触发 | 粗意图「靠近 / 过来一点 / 陪我」 |
| 轨迹 | **坐姿贴墙平移 10–15cm，脚不离「地」**；沿墙意象面轻轻滑近，不上浮、不跳、不扑镜头 |
| 时长 | 慢、短，单段约 1.5–4 秒，到点即停 |
| 光效 | 光只呼吸半拍，**不做追光秀**、不扫光带路 |
| 可关项 | 关麦时若用户点「靠近」类按钮，可用同一平移；可关光只保留位移 |
| 红线 | Y 轴不上浮；禁止飞近、跳近、放大扑出 |

全部核心参数【已确认】。

| 项 | 写法 |
| --- | --- |
| 触发 | 粗意图「闲聊」；寻找或靠近时原「观察」动作并入本段复用，不另立状态名（并入方式【本草案补全】） |

### 5.4 晚安 / 道具，以及一次收尾【本轮故事与 Demo 的执行默认】

| 项 | 写法 |
| --- | --- |
| 触发 | 分两路：**找到后的一次轻互动**走插片确认 / 轮廓溶换（可跳过）；**晚安**或用户点结束时关光。粗意图「道具」可走插片溶换 |

## 6. 状态过渡（【本草案补全】，须平缓）

1. **出现：** 不瞬切、不从天花板掉下。先在落点淡入成停留，再收成坐下。须有软阴影；可用淡落点环证明被放在平面上。出现 ≤3s（【已确认】）。无立面时仍坐在桌面，用软阴影建立重量，禁止上浮补「灯感」（Design 第一次验收已采纳）。
2. **坐下 → 躲藏：** 沿墙 / 沿平面滑向预设偏移，同时降低不透明度与边缘光。建议 1.5–3 秒。
3. **躲藏 → 回位 / 坐下：** 反向滑回落点再坐正。禁止突然实体化在镜头前。
4. **坐下 ⇄ 闲聊（原「观察」已并入）：** 只动插片光或极小转向，不切镜头、不换整套骨骼。单段结束必须回到坐下。
5. **结束：** 找到后的一次轻互动按第 5.4 节做插片确认 / 轮廓溶换（可跳过）；晚安或用户点结束时关光，然后静帧。禁止自动连弹下一局。

失败或拒相机：走屏内同构，**不能改回悬浮方案**。

## 7. 可关麦与语言边界

- 常驻可关麦；关后立即停听。也可「先看着」：静坐在场，无语音采集。【已确认】
- 落位、躲藏、点找、「算了」、回位、一次轻互动，全部不依赖开麦。【已确认】
- 角色无 TTS。系统提示字幕级减字。开麦前须告知：可能采集语音，目的仅触发角色回应，可关。【已确认】
- **不可说：** 助眠、安神、改善睡眠、治疗、保证入睡、睡眠评分、疗效；心理咨询、情绪诊断、读心、焦虑 / 抑郁 / 失眠标签；「守护你睡着」；倒计时、抓住它、吓你一跳、排行、连胜。
- 定位：成人向过夜仪式感与角色互动；不定位儿童睡眠产品，不定位医疗助眠。验收不挂钩睡眠评分。

## 8. 开放问题与已采纳建议

1. **停留（Design 建议，时长仍交 UX 定量）：** 作为出现后、躲藏前（以及回位后轻互动前）的短过渡拍保留，可跳过，不升成与「坐下 / 躲藏」并列的官方状态名。本表第 2 节已按此改写，秒数仍供 UX 定量。
2. **观察（Design 建议）：** 并入静默层「闲聊」，不另立状态名。本表第 3 节改为闲聊复用说明，不再当作独立官方状态。
3. **无立面时的落点（已采纳）：** 仍坐在桌面，用软阴影建立重量，禁止上浮补「灯感」。需 AR 真机验证，但不回退为悬浮方案。
4. **一次收尾：** 本轮按「本轮故事与 Demo 的执行默认」采用方案 A（见第 5.4 节；Design 第一次验收建议的默认写法）。这不是已立项锁定，也不是用户已拍板。正式锁定仍须用户在 CIO 窗口确认；财务底稿继续标待立项，不覆盖那一页。
5. **与 Story 对齐：** Story 已收口，只对齐为何这样动，不改已锁定动作参数。

## 9. 为何这样动（对齐 Story 正式收口，动作参数不变）

依据正式收口的 `stories/03-影盏-成长故事.md` 与 `stories/00-五角色差异对照.md`。本节只补充解释，不改上文已锁定的触发、轨迹、时长、光效与红线。

- **坐下（默认稳态）：** 先有落点，才有贴墙的影子。它以「被放在这里」为在场方式，坐实后黏在面上；重新飘起或压成白纸扁剪影，等于退回还没有落点的日子。所以默认是坐着的暖琥珀内透光侧影，不是悬着的灯。
- **停留（短过渡拍，不升为官方状态名）：** 关系从「放在墙上或桌上」开始，不是从飞到面前开始。落位后先有一段被放下的停留，再收成坐下。被放下是安定，不是被冷落。
- **闲聊（原「观察」已并入）：** 看人的方式顺着墙走：先看见落点附近的墙根和插片轮廓，再偶尔偏向用户所在的方向，不对视施压。好奇，但沿墙观察，不绕场。插片镂空眼明暗，是换内容参数，不是换脸。
- **躲藏：** 藏时沿墙滑向墙根光边，身体仍暗示坐或靠，不变成飘在墙中的剪纸。线索用插片轮廓或极淡呼吸光，因为插片是它愿意让人补上的内容包。
- **确认 / 靠近：** 性格是「被放下的灯」——有重量、有软阴影、有一拍就停的呼吸光。陪伴是并排坐在同一面墙的这一侧，所以靠近只做贴墙短移，不飞到面前。
- **一次收尾（方案 A，本轮故事与 Demo 的执行默认）：** 找到后用插片确认，是突出内容包记忆点；关光留给结束 / 晚安，避免两个收尾抢同一拍。长期关系靠更换插片变熟，而不是靠它学会说话或离地更近。这是 Design 第一次验收建议的默认写法，不是已立项锁定，也不是用户已拍板。正式锁定仍须用户在 CIO 窗口确认；财务底稿继续标待立项，不覆盖那一页。
- **无立面时仍坐下：** 只有桌面、没有立面，也坐在桌面上，用软阴影和坐姿建立重量，仍禁止上浮补「灯感」。

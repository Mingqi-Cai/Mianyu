# 不允许只悬浮的反例说明（Demo · 以影盏为重点）

> 撰写：CMQ-IP-Behavior · 2026-11-12（Asia/Shanghai）  
> 给动画、AR 资产与 UX：角色必须在真实平面上坐、靠、蹲（或阑岚的靠窗站），不能只用悬浮表示「在场」。  
> 本页写具体反例与正确做法对照。**重点写影盏**，并点明其他角色同样不许只悬浮。不写身世。

影盏从 V1 到 V2 的已确认纠正，就是把易有飘浮感的侧影灯伴，绑死为「坐着的影」。V3 展示继续锁定：默认坐 / 靠 / 蹲；禁止飘浮；禁止白纸扁剪影；Y 轴不上浮；靠近时坐姿贴墙平移，脚不离「地」。下列反例如在 Demo 出现，即视为不合格。

---

## 1. 影盏：反例与正确做法

| 反例（不要做） | 为什么不行 | 正确做法 |
| --- | --- | --- |
| **从天而降 / 从天花板掉进画面** | 出场变成坠落特效，落点是事后补上的，观感仍是悬空物 | 在用户点按的桌面、地面或墙边**直接淡入**，先有软阴影和坐姿，再进入短暂停顿或坐下。出现 ≤3s，不瞬切、不掉落 |
| **Y 轴上浮补「灯感」** | 把「它是一盏灯」理解成必须离开桌面发光；与「坐着的影」直接冲突 | 灯感用**暖琥珀内透光**和一拍即停的边缘呼吸光完成。身体底面贴合检测平面，阴影落在同一平面。没有立面时也坐在桌面上，**仍禁止上浮** |
| **无落点悬空待命** | 点按平面失败或尚未命中时，角色先在屏幕中心漂着等平面 | 没有可用平面就走**屏内同构**：在模拟平面或暖雾底上点按落位。不能用悬浮当失败态的「将就方案」 |
| **突然放大 / 扑向镜头** | 惊吓，且靠近变成冲镜，而不是贴墙平移 | 靠近 = 坐姿贴墙平移 **10–15cm**，脚不离「地」，光只呼吸半拍。找到回位时反向滑回再坐正，禁止「啪」地出现在镜头前 |
| **躲藏时飘进墙里或变成飞着的剪纸** | 藏点如果离开承面，躲猫猫会变成飘移隐形，而不是墙根光边的坐 / 靠 | 藏点意象是**墙根光边**。用相对落点 2–3 个预设偏移 + 淡出 / 半透明；身体仍暗示坐或靠。不做真家具遮挡，也不做墙中悬浮 |
| **用持续扫光、追光秀或闪光雨代替落地** | 高唤醒，并且用光效掩盖「没有坐实」 | 光一拍即停。确认只用边缘呼吸光半拍；线索只用极淡呼吸光或插片轮廓，不是闪光弹 |
| **白纸扁剪影吊在空中** | V3 改稿已明确要回到暖琥珀内透光坐姿 + 木质落点 | 材质内透、有体积感；坐在落点上，墙上可有软阴影，但人是坐着的灯，不是一张被钉住的纸 |
| **跳起、飞近、升到人脸高度再打招呼** | 直接破坏 Y 轴不上浮与无惊吓 | 近距离最多坐正 1 拍表示察觉，随即回安静坐姿。不站起、不扑近 |
| **用表情包、脸部变形或姿态滑条制造「活着」的感觉** | 插片是内容包，不是换装或骨骼表演；02 类姿态库勿进 Demo 主路径 | 闲聊用当前插片镂空眼明暗交替 2 次；换插片参数或轮廓溶换，不换一张脸 |

一句话验收：关掉所有光效之后，影盏是否**仍然坐在一张桌子或一块地板上**？如果关掉光它就「没了」或还在半空，就是只做了悬浮。

---

## 2. 出现、靠近、躲藏、结束：正确运动方向

只允许沿平面或沿墙的水平 / 贴面移动，不允许作为主运动的垂直升起。

1. **出现：** 落点淡入 → 短暂停顿 → 坐下。阴影先于或同时于身体出现。
2. **靠近：** 贴墙滑 10–15cm。位移向量贴面，不走抛物线。
3. **躲藏：** 沿墙滑向墙根偏移，同时变淡。不是向上隐入天花板，也不是向镜头飞来再消失。
4. **回位：** 原路贴面滑回，再坐正。
5. **结束：** 找到后的一次轻互动用插片确认 / 轮廓溶换（可跳过）；关光留给晚安或用户点结束，静帧留在落点。不飞走谢幕。【本轮故事与 Demo 的执行默认】这是 Design 第一次验收建议的默认写法，不是已立项锁定，也不是用户已拍板。正式锁定仍须用户在 CIO 窗口确认；财务底稿继续标待立项，不覆盖那一页。

过渡建议 1.5–3 秒（本草案补全，供 UX 定量），慢、短、可被看清「它在面上移动」。

---

## 3. 其他角色同样不许只悬浮

五人空间结缘不同，但**都不许用悬浮代替在场**。下列为要点，不是新编动作。

| 角色 | 必须看见的着生 | 特别容易犯的悬浮错 |
| --- | --- | --- |
| 霁霁 | 坐在檐下 / 角落 / 床边地面；内收落座仍在面上 | 做成飞龙盘旋或扑向镜头；用角灯把身体托离地面 |
| 守绒 | 四足蹲在门边地面，门墩感来自重量 | 做成会飞的狮或跳扑；前倾变成离地扑咬 |
| **影盏** | 坐 / 靠 / 蹲在桌面或墙边，脚不离「地」 | 见第 1 节，风险最高：灯具本能会被做成漂浮夜灯 |
| 泊泊 | 软圆墩坐在行李旁或地面垫上 | 做成飘向窗的气球；靠近变成滚空或弹跳离面 |
| 阑岚 | **靠窗站**，雾边缘仍须接触窗台 / 地面，不是飞天 | 「雾灵」被做成精灵飞天或在窗前悬空旋转；光斑闪成可升空的粒子 |

阑岚的默认姿态是站而不是坐，这不等于允许悬浮。站要站在窗边的可理解承面上；展示稿已写「无精灵飞天」。

---

## 4. 技术失败时也不许退回悬浮

**【已确认】** 拒相机、超时、弱光丢平面一次、机型不支持，均走屏内同构玩法：在模拟平面或暖雾底上点按落位，状态机与 AR 主路径相同。

不正确：AR 丢平面后把影盏改挂在屏幕中心或镜头前漂着「先撑住」。  
正确：失败一次即降级屏内，角色仍被「放下」在一个可见平面上，带软阴影或淡落点环。弱光成功率尚未真机验证，但不能用悬浮当备用方案。

Demo 不做：真家具遮挡、人体跟随、暗房满血 6DoF、姿态库 / 表情滑条。这些缺失不构成「只好悬浮」的理由。

## 5. 自检清单（给出图与动画）

验收影盏（及其他角色）镜头时，逐条打叉即需返工：

- [ ] 出场是否未从天而降、未瞬切在半空？
- [ ] 关闭呼吸光 / 角灯 / 纸灯后，身体是否仍贴在桌面、地面、门边或窗台？
- [ ] 靠近是否只有贴面短位移，没有 Y 轴上浮、放大扑出？
- [ ] 躲藏是否仍能读出席地坐 / 靠 / 蹲 / 站，而不是墙中或空中的剪纸？
- [ ] 是否无惊吓扑出、无 TTS、光是否一拍即停？
- [ ] 屏内降级是否同样有落点，而不是中心悬浮？

本页不替代 `01-影盏-Demo状态表.md` 的状态参数；只约束「不要用悬浮冒充在场」。

Story 正式收口后的解释与本页一致：影盏须先被放下、坐实，才有贴墙的影子；禁悬浮的验收标准不因此改写。

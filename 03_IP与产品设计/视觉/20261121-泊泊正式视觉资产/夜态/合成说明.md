## 收光参数（沿用已锁定观感，不是新编统一色票）

对标准坐姿切图的 RGB 做曝光 0.72、伽马 1.10、暖调 1.04；**Alpha 与标准切图逐像素相同**。光晕由官方切图轮廓外扩 120px 生成，暖色，供角色背后叠加。

| 文件 | 尺寸 | 用法 |
| --- | --- | --- |
| `bobo-figure-night.png` | 1010×737 | 替换屏内角色图（外形与标准切图一致，只做收光） |
| `bobo-glow.png` | 1250×977 | 放在角色图后方，默认可见，不要 `opacity: 0` |
| `bobo-home.png` | 1250×977 | 主页用：透明底，已含光晕，避免再放带大块奶油工作室底的官方原图 |
| `bobo-insert-a.png` 与 `@2x` | 136 / 272 | 同一枚官方圆徽的夜态收光。无 insert-b |
| `bobo-insert-a-day.png` | 136 | 白日 / 标准光照下的同一枚徽，便于对照 |

光晕比角色图每边多 120 源像素：120/1010 ≈ 11.88%。建议：

```css

  top: -11.88%;
  width: 123.76%;

  z-index: 0;
  pointer-events: none;
  opacity: 0.92;
}
```

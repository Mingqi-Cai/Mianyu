## 红线

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 不得改成苗族人物 | 通过 | 无银冠、无满额尘帘、无牛角、无花盘银片或珊瑚松石串，不是民族服饰换装。仍是卸下锣鼓的守夜狮 + 原创短挂额饰。 |
| 不得复制具体传统头饰 | 通过 | 视觉上只保留「发际固位 + 短垂」的结构启发，未做成某一可对号的传统头饰样式。 |
| 不得出现空白旅签 / 锣鼓 | 通过 | 互动点仍是额头守结，不是挂牌，也不是锣鼓。 |
| 配饰不得扩散到整体形象 | 通过 | 无整体气质重做，无头部比例改动，胸前暗红绳结保持原样。若后续稿把换装感扩到鬃形、面容或体态，应打回并只保留额饰改动。 |

## 已知点（Design 已收下，不作为本轮新的退回理由）

1. 眉上额绒空带仍略窄于 V3 贴额稿，因为上方要露出极短悬绳。后续若再收，只可略提固位或再缩绳，不得把结做大或下移。
2. `03` 的毫米级悬空间隙仍含蓄，静息微光弱于 `02`。读悬空与完整发光请同时看额饰正本 `04` 与 `08`。
3. 固位藏进鬃毛，全身正面不够显眼，需靠 `04` 与 `08` 读全三件式。此取舍保持。

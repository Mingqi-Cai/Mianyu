## 设计要点（提要）

- 固位藏进鬃毛发际线，悬绳为极短暗红浅 V，主坠仍是暗金盘长守结，左右各一枚极小暗金豆。
- 守结中心接近 V3 贴额结的中上额高度；下沿到眉峰之间留出清楚的额绒空带，可容纳极慢微摆与轻触收光。
- 守结与额绒之间设计为约 2–4 mm 悬空间隙，不贴死、不压脸。
- 眉、眼、鼻、嘴全部外露，不影响 AR 识别。
- 材质只有暗金 + 暗红绳。无银冠、无牛角、无长尘帘、无旅签牌、无锣鼓、无文案。
- 01 右侧与 02 带出图直接生成的静息微光；完整发光以 04 为准。
- 完整说明见 `05` 与 `07`。

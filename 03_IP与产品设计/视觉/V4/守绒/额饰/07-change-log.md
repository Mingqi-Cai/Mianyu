### 结位如何上提

- 方法：提高鬃毛发际线上的双点固位，并把两根暗红悬绳再缩短，使守结中心接近 V3 贴额结的中上额高度。没有把结做大，也没有继续下移。

## 改了什么（相对 V3 的设计变更，仍成立）

1. **装挂方式**：V3 的贴额暗金守结，改为悬挂式额饰。守结不再贴死在额绒上，而是由短绳悬在额前。
2. **增加固位**：在鬃毛发际线增加双点暗金扣环（设计上也可换成极细暗金横杠），藏进卷鬃，作为悬挂原点。正面实稿选择了更隐蔽的双点固位，避免出现宽额带或头箍感。
3. **增加悬绳**：两根极短暗红细绳，与胸前绳同一语言，呈浅 V 垂下，把守结送到中上额。
4. **增加极短第二层**：守结左右各一枚极小暗金豆，下沿设计为不超过眉尖，用于形成很轻的层次，而不是长帘。
5. **动态口径对齐**：把静默沟通里「守结绳可极慢晃动一拍」落到可分件的悬绳层，而不是让整颗头或整张脸跟着晃。眉上额绒空带即为这一拍预留。
6. **金光作为状态**：正面静帧为直接生成的「微光一息」；细节特写为更完整的局部暖金光。互动记忆点不变：一闪、微光一息、轻触收光。

## 保持了什么

1. 卸下锣鼓的守夜狮身份，以及门墩蹲守的姿态与门边场景。
2. 鬃毛与面容：丰满卷曲鬃毛、圆耳、柔和下垂眼、棕色眉与鼻、安静略带倦意的表情。
3. 体色与体型：暖柔葵色/焦糖色毛，奶油色胸腹、嘴筒与肉垫，柔软毛绒质感。
4. 胸前暗红绳结，以及绳下的小青铜/暗金小结坠。
5. 守结本身仍是暗金盘长结，仍是额饰的主识别物，不是新的符号系统。
6. 禁空白旅签挂牌；禁锣鼓；禁「守护你入睡」类文案；图中无营销文案。对照图只标注 V3 / V4。
7. 角色不是苗族人物，配件也不是某一支系传统头饰的换装。

## 过程取舍（含第一版与改稿）

- 第一版曾尝试把固位横杠明确画在额表上：三件式更一目了然，但容易读成细头箍，不用作正式正面稿。这一取舍在改稿中保持。
- 第一版曾出现守结下方多余红穗、以及更侧近景压眉的废稿，均已弃用。改稿时仍不用会压眉的大侧面来强调空隙。
- 第一版用后期给正面叠加金光，金属被冲成贴纸，已弃用。改稿按验收要求改为出图直接生成微光。
- 改稿出正面时，若以旧 V4 低结稿为主要视觉参考，模型仍会把结往下拉。有效做法是把任务写成「编辑 V3：结的位置与大小保持不动，只补上短绳固位」，并以正确结位的目标稿作为附加参考。

## 已知风险（不粉饰）

1. **眉上空带仍略窄于 V3 贴额稿**：改稿后空带已经清楚，不再贴眉，也可以容纳微摆；但因为上方要露出极短悬绳，空带还是比 V3 略窄。若再收，只能继续略提固位或再略缩绳，不能把结做大或下移。
2. **毫米级悬空间隙在角色实稿里仍然偏含蓄**：这是第一版已说明、且本次验收允许保留的点。正面和 3/4 侧能读出「绳在垂、结在额前」，但 2–4 mm 的空气感不够戏剧化。请同时看 04 与 08。
3. **03 的静息微光弱于 02**：01 右侧与 02 的微光已可辨；同场景 3/4 侧结位正确、空带清楚，但金光更克制，几乎接近无光。完整发光仍看 04。若需要套图完全一致，可在后续只补 03 的微光，不要再改结位。
4. **固位件在正面仍较隐蔽**：双点扣环在鬃毛中只露出很小的金点，三件式的①仍需靠 04 与 08 读全。这是为避免头箍感而做的取舍，验收已肯定可保持。
5. **3/4 侧不是纯侧面**：正式 03 仍是同场景轻度 3/4，按验收要求没有改用会压眉的大侧面。纯侧面请以 08 为准。

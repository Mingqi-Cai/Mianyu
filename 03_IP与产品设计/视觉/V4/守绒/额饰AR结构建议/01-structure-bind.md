# 01 · 部件、层叠与分件绑定

日期：2026-11-12（Asia/Shanghai）  
正本：配饰 `05-structure-and-design.md`、`08-structure-diagram.jpg`、`09-design-first-acceptance.md`  
性质：结构分解与绑骨【制作建议】。建议命名与层级尚未创建，【未实现】。不得当作已完成绑定。

## 1. 三件式（【已锁定】）

第二层侧豆并入悬绳层，避免再增加独立大动作零件。层次关系是「发际固位 → 短垂 → 中央主坠 + 极短侧点」，不是多层尘帘，也不是花盘银片叠饰。

| 件 | 名称 | 位置与做法（【已锁定】） | 绑定职责（【制作建议】，【未实现】） |
| --- | --- | --- | --- |
| ① 固位 | 双点暗金扣环（可选极细暗金横杠） | 沿鬃毛发际线水平固位，藏进卷鬃。不是银冠，也不是宽额带。正面几乎只看到两根细绳从鬃毛中垂出 | 悬挂原点与受力点。与头部颅骨刚性绑定，不随表情位移。无独立动画 |
| ② 悬绳 | 两根极短暗红细绳 | 与胸前暗红绳同一颜色与拧绳语言，由固位点浅 V 垂下，长度仅够把守结送到中上额 | 本配件唯一允许的动作层。可独立做「极慢晃动一拍」；幅度极小，轨迹不扫过眉眼，不带动身体 |
| ③ 守结主体 | 暗金盘长守结 | 仍是 V3 那枚结的造型语言，悬在中上额前方，与额绒之间约 2–4 mm 空隙 | 随悬绳做极小摆动。互动触点与发光体。不可独自做大幅度位移 |
| ④ 第二层（并入②） | 左右各一枚极小暗金豆 | 位于两侧短绳中段，体量远小于守结。下沿不得超过眉尖，更不得靠近眼裂 | 随绳微动，不单独做大动作，不另建一套动画控制器 |

正面正本选择更隐蔽的双点扣环，避免头箍感。可选极细暗金横杠仅作为结构备选，默认不启用；若启用也必须藏在发际线内，不得读成宽额带。【已知可保留】固位在全身正面不够显眼，需靠 `04` 与 `08` 读全，不在绑骨时把扣环外移或放大。

## 2. 建议骨骼 / 挂点命名（【制作建议】，尚未建骨）

前缀 `SR_Acc_` 仅是本包建议，可在与角色骨骼规范对齐时微调，但不得改变三件式层级，也不得把挂点挂到表情骨上。下列名称均【未创建】。

| 建议名称 | 对应件 | 建议父级 | 允许的运动 |
| --- | --- | --- | --- |
| 角色颅骨刚性骨（沿用角色头骨，不另造一套头） | 头部 | 角色脊柱 / 颈 | 只随身体与头部动作。本包不承担角色身体绑骨 |
| `SR_Acc_Anchor_L` / `SR_Acc_Anchor_R` | ① 左右固位扣环 | 颅骨刚性骨 | 无独立动画。不随眉、眼、口、鼻、下颌骨或面部 blendshape 位移 |
| `SR_Acc_Anchor_Bar` | ① 可选极细横杠 | 同颅骨，或约束在两点之间 | 默认隐藏 / 不启用。无独立动画 |
| `SR_Acc_CordRoot` | ② 浅 V 的单一摆动驱动 | 由左右固位共同约束，或挂在两点中点并随两点 | 仅「极慢晃动一拍」的驱动源，用来保持浅 V 不被左右绳拆散 |
| `SR_Acc_Cord_L` / `SR_Acc_Cord_R` | ② 左右悬绳 | `SR_Acc_CordRoot` | 随驱动做极小角位移，不各自做独立物理摆锤 |
| `SR_Acc_Bead_L` / `SR_Acc_Bead_R` | ④ 侧豆 | 各自悬绳中段 | 随绳微动，无独立大动作 |
| `SR_Acc_Knot` | ③ 守结 | `SR_Acc_CordRoot` 下端，或由两绳下端约束到同一目标 | 随悬绳极小摆动；承载发光与触点；不可独自大幅位移 |
| `SR_Acc_Knot_Touch` | 轻触收光用的触碰体积 | `SR_Acc_Knot` | 无动画。体积须覆盖可点范围，但不得涨到挡住眉眼识别面 |

胸前暗红绳结不纳入本额饰绑定，保持角色既有装挂，不与额饰骨骼耦合。

## 3. 建议父子关系（【制作建议】，【未实现】）

```
角色身体
 └─ 头部 / 颅骨刚性骨          ← 身体运动只传到这里
     ├─ SR_Acc_Anchor_L        ← ① 发际固位，无动画
     ├─ SR_Acc_Anchor_R
     ├─ SR_Acc_Anchor_Bar      ← 可选，默认关闭
     └─ SR_Acc_CordRoot        ← ② 唯一摆动层（浅 V 保持）
         ├─ SR_Acc_Cord_L
         │    └─ SR_Acc_Bead_L ← ④ 并入绳层
         ├─ SR_Acc_Cord_R
         │    └─ SR_Acc_Bead_R
         └─ SR_Acc_Knot        ← ③
              └─ SR_Acc_Knot_Touch
```

原则：

- 两根悬绳不要做成两个独立单摆。用一个 `CordRoot` 驱动，保证二维缩小后仍读成「短 V 绳 + 中央暗金守结」。
- 守结挂在绳层下端，与额绒保持设计空隙，不把顶点蒙皮到额绒或面部。
- 固位扣环可以有极少量鬃毛覆盖，但扣环骨骼本身必须跟颅骨，不跟鬃毛动态骨。

## 4. 层叠与连接点（【已锁定】形态 + 【制作建议】连接）

| 连接 | 视觉位置 | 建议做法 |
| --- | --- | --- |
| 固位 ↔ 发际 | 鬃毛发际线左右两点，水平对齐，藏进卷鬃 | 扣环网格可部分没入鬃毛表面；悬挂原点取扣环中心，受力走颅骨，不走毛发 |
| 固位 ↔ 悬绳 | 两根细绳从扣环垂出；正面几乎只看到绳，看不到头箍 | 绳的上端点死约束到对应 Anchor，不得滑脱或拉长 |
| 悬绳 ↔ 侧豆 | 左右短绳中段各一枚极小暗金豆 | 豆是绳上的子网格，随绳走 |
| 悬绳 ↔ 守结 | 浅 V 下端与盘长结上方环扣相接 | 结的悬挂点在结的上部，不从结心穿孔到额面 |
| 守结 ↔ 额绒 | 中上额前方，约 2–4 mm 可见空隙 | 结的网格不与额绒碰撞、不嵌入、不贴死。空隙预留见 `02` |

不得增加额外连接件（银链、穗、牌、第三根中绳、宽额带）。

## 5. 表情骨骼隔离（【制作建议】，【须真机验证】）

目标：面部表情与鬃毛微动不得把额饰拉歪、压眉或改变 2–4 mm 空隙。

1. 固位只跟颅骨刚性骨，不跟眉骨、眼骨、睑骨、鼻骨、口周骨、下颌骨。
2. 额饰顶点权重不得画到面部 blendshape / morph 上。守结、绳、豆、扣环都不要加入表情形变。
3. 鬃毛若有动态骨或形变，只允许覆盖固位的视觉遮挡，不允许成为父级或权重来源。若鬃毛形变会顶到绳或结，应在鬃毛侧做避让，而不是把结位下调。【已知可保留】结位已收口，不得下移。
4. 「鬃毛轻顿」（确认）是角色头部 / 鬃毛动作，额饰只随颅骨整体轻顿；若同时叠加「极慢晃动一拍」，仍以绳层小幅度完成，不让表情骨参与。
5. 「低头压鬃」（晚安）时，额饰随头低下，绳层建议锁定或进一步收幅，避免俯角下的摆锤拍到眉眼。该姿态的清空须单独验收，见 `03`。

以上隔离尚未绑骨，也未在真机表情跟踪下验证。

## 6. 分件绑定对 AR 的意义（建议，非已实现能力）

- 固位与头锁定，保证门墩蹲守、前倾回位时悬挂原点不漂。
- 摆动只发生在悬绳层，身体和面部不必为额饰另做一套动画。
- 守结可单独控制发光状态（一闪 / 微光一息 / 收光），不必点亮整张脸。
- 触点挂在结上，交互锚是守结，不是旅签，也不锁成必须贴额。

上述均为制作准备，不是已可调用的运行时接口。

# 05 · 制作准备与验收清单

日期：2026-11-12（Asia/Shanghai）  
性质：制作准备。下列规格均为【制作建议】。模型、材质、动画、LOD、碰撞均【未制作】，完成后仍【须真机验证】，不可当作已可上线。

结构示意见同目录 `06-ar-bind-safety-envelope.svg` / `.png`。该图仅为示意，不是已做好的模型，不替代配饰 `02` / `03` / `04` 或 `08`。

## 1. 拓扑（【制作建议】，【未制作】）

- **分件建模**：固位扣环、左右悬绳、左右侧豆、守结，按三件式分件；侧豆可与绳做层级子网格，但不合并成一块无法分件绑定的整体。
- **守结**：保持 V3 / V4 正本的暗金盘长结造型语言，有可读的盘绕体积，不要做成贴额圆片或贴纸卡。近景（对应视觉稿 `04`）须能读出结的厚度与盘绕；不要发明新结样。
- **悬绳**：两根极短拧绳，截面有拧股，不要做成塑料圆柱或扁平丝带。长度只够把结送到中上额，禁止加长。
- **固位**：双点暗金扣环体量小，允许部分没入鬃毛；不要做成露出的银冠或宽额带。可选横杠默认不建或建好隐藏。
- **侧豆**：极小，球形或近球形暗金豆，明显小于守结；下沿不超过眉尖。
- **干净的背面与连接**：守结背面低凸起，不戳额绒；绳与结、绳与扣环的连接点干净，无多余穗、牌、第三根中绳。
- **比例**：以配饰 `02`、`04`、`08` 的结位与空带为准，禁止参照 `_work/review1-superseded/` 低结稿。

角色头部与鬃毛拓扑不在本包范围。额饰与额绒之间只保留空隙，不做布尔合体。

## 2. 材质与发光（【制作建议】，【未制作】）

- 只有暗金金属 + 暗红细绳。暗金为较暗、低到中等粗糙度的金属，不是亮银、不是高反射金贴纸。
- 绳与胸前绳同一颜色与拧绳语言，织物 / 纤维感，不是塑料管。
- 发光只在守结局部：柔和暖金，不铺满脸，不把金属冲成贴纸。
- 建议发光分档（实现【未制作】，视觉对正本）：

| 分档 | 对应 | 视觉参考 |
| --- | --- | --- |
| 静息微光 | 闲聊「微光一息」；默认在场 | `01` 右侧与 `02`（出图直接生成的可辨微光，弱于确认闪光，也弱于 04） |
| 完整发光 | 记忆点更完整的局部暖金 | `04-v4-forehead-detail.jpg` |
| 一闪 | 确认 | 在完整发光附近做短促一闪后回到微光；一拍即停 |
| 收光 | 晚安轻触 | 由微光或一闪收到暗金无光或极弱残光；结的体积仍在 |

【已知可保留】`03` 的静息微光弱于 `02`。制作时以 `02` 与 `04` 为发光档位参考，不要为了套图一致去改结位。光是局部的，禁止屏幕空间大光晕盖住眉眼识别面。【须真机验证】曝光与识别干扰。

## 3. LOD 与二维缩小可读性（【已锁定】要求，方案【未制作】）

缩小后仍须读成「短 V 绳 + 中央暗金守结」，不能退化成贴额圆点、宽额带或满额帘。

| 档 | 建议可读底线 |
| --- | --- |
| 近景 / 高模 | 三件式可读，扣环在发际可被找到，拧绳、盘长结体积、侧豆、侧视空隙都在 |
| 中距 | 短 V + 中央结清楚；侧豆可简化；固位可更隐，但不能出现头箍剪影 |
| 远距 / 低模 / 二维缩小 | 至少读出「短 V 绳 + 中央暗金结」；宁可变细绳，不可把结收成圆点，不可把绳拉成额带或帘 |

各档都不得压眉挡眼。低模也要遵守眉上安全线和空隙，不能为了省面数贴回额上。尚未制作任何 LOD。

## 4. 动画曲线限制（【制作建议】，【未制作】）

- 默认曲线为零：静息、闲聊不摆绳。
- 「极慢晃动一拍」：单次缓入缓出，到达小峰值后回到零，不回弹成第二次摆，不循环。
- 角位移钳制在 `02` 建议起算范围内，并再以安全线做最终裁切。出包络的关键帧不合格。
- 身体快速移动、回蹲、低头过程中，绳层权重要降到接近零。
- 发光曲线与绳摆可同段，但光必须一拍即停，不得靠长呼吸光带动绳。
- 禁止物理绳、布料、连续噪声。
- 低头压鬃、门边前倾要有专用检查，不只验正视。

曲线秒数交 UX / 动画定量，须落在静默沟通单段约 1.5–4 秒的观感里，【须真机验证】。

## 5. 碰撞与安全距烘焙（【制作建议】，【未制作】）

建议至少烘焙 / 预留下列不可进入区（头部局部空间）：

1. 额绒外表面外扩后的禁入壳（用于保持 2–4 mm 空隙，防止贴死或穿模）。
2. 眉上安全线以下的禁入带（守结、侧豆、绳的下沿都不得进入）。
3. 眼周盒子（任何一帧不得拍到）。
4. 鼻梁与嘴部外围（低头、前倾时的扫掠检查）。
5. 侧豆下沿相对眉尖的限高。

检查姿态至少包括：正视静息、一拍摆动的左右前后极值、靠近回蹲、前倾回位、晚安低头。以烘焙或动画钳制保证，不依赖运行时再「弹开」（弹开会看起来失稳）。全部【未制作】，【须真机验证】。

轻触体积只包守结，不扩大到清空区。

## 6. 制作顺序建议（不是已排期承诺）

1. 按正本结位做分件阻塞模，先卡固位、绳长、结位、空隙、空带，不做材质。
2. 挂到临时颅骨上，验正视 / 侧视 / 低头，对照 `02` / `03` / `04` / `08`。
3. 再做分件绑定、表情隔离、包络钳制。
4. 材质与分档发光。
5. LOD。
6. 与角色身体、CIO-AR 对齐后真机验证。

任何一步完成都不等于「已可上线」。没有真机验证，不能宣称识别、摆动或发光成立。

## 已锁定形态（不得改设计）

鬃毛发际双点固位 + 极短暗红浅 V 悬绳 + 原暗金盘长守结轻悬中上额 + 左右极小暗金豆。

配件是「三件式可分件绑定」。侧豆并入悬绳层，不是第四个大动作零件。材质只有暗金 + 暗红绳。无银冠、无宽额带、无锣鼓、无扑咬、无空白旅签挂牌。

硬性清空：眉、眼、鼻、嘴必须完全外露。守结中心接近 V3 贴额结的中上额高度；下沿到眉峰之间留出额绒空带；与额绒约 2–4 mm 悬空间隙。摆动只允许悬绳层「极慢晃动一拍」，任何一帧不得越过眉上安全线、不得拍到眼周。

二维缩小后仍须读成「短 V 绳 + 中央暗金守结」，不能退化成贴额圆点、宽额带或满额帘。

## 【已知可保留】（09 已接受，不得在 AR 建议里「修正设计」）

1. 眉上空带略窄于 V3（上方要露出短绳）。后续若再收，只可略提固位或再缩绳，不得把结做大或下移。
2. `03` 毫米级悬空间隙含蓄，静息微光弱于 `02`，须结合 `04` 与 `08` 阅读。
3. 固位藏进鬃毛，全身正面不够显眼，需靠 `04` 与 `08` 读全三件式。

## 静默沟通接口提要（【已锁定】口径）

- 确认：鬃毛轻顿 + 额头守结暗金一闪。
- 靠近：外移半步，回到门墩位蹲稳；不追人脸。
- 闲聊：守结微光一息，身体不动。
- 晚安：低头压鬃；轻触额头守结收光（挂件在头上，不用空白牌子）。
- 力量感来自安静蹲守；前倾在场时重心回到门墩位蹲稳。守结绳可极慢晃动一拍。

# 03 · 姿态落位与悬挂稳定

日期：2026-11-12（Asia/Shanghai）  
正本：静默沟通最终版（守绒：门墩蹲守、前倾回位、守结绳可极慢晃动一拍）；配饰 `05` 第 4 节  
性质：落位与稳定约束建议。动画与物理均【未制作】，姿态稳定【须真机验证】。

## 1. 姿态口径（【已锁定】）

力量感来自安静蹲守，不来自扑咬、锣鼓或大幅甩挂件。

| 姿态 / 动作 | 身体 | 额饰 |
| --- | --- | --- |
| 默认静息（门墩蹲守） | 四足蹲在门边地面，身体几乎不动 | 悬绳与守结基本静止；正面可见「微光一息」 |
| 确认 | 鬃毛轻顿 | 额头守结暗金一闪；可叠加绳层「极慢晃动一拍」，然后复位 |
| 靠近 | 外移半步，回到门墩位蹲稳；不追人脸 | 随头部整体移动；不另做追脸摆荡。回蹲后恢复静止，至多一拍微摆 |
| 闲聊 | 身体不动 | 守结微光一息；绳层保持静止，不借闲聊做循环晃动 |
| 晚安 | 低头压鬃 | 轻触额头守结收光。挂件在头上随头低下；绳层应收幅或锁定，避免俯角失稳 |
| 前倾在场 | 重心回到门墩位蹲稳 | 只允许配件微动，不得因前倾甩成钟摆 |

坐、靠不是守绒的默认官方姿态。若场景出现短暂的坐或身体重心调整，仍须四足 / 底部着地，额饰规则与蹲守相同：身体带动头部，配件只允许绳层那一拍。不得把守绒做成会飞的狮或离地扑咬。

## 2. 运动传递关系（【制作建议】，【未实现】）

```
身体位移 / 蹲稳 / 外移半步
  → 头部（颅骨）
    → 固位（刚性跟随，无二次惯性）
      → 悬绳层（唯一可加「极慢晃动一拍」的地方）
        → 侧豆、守结（跟随）
```

- 身体可以动，头部跟着动，固位必须跟死颅骨，不能再做一个「头饰延迟」。
- 配件不得反向带动身体、颈部或表情。
- 除绳层那一拍外，额饰不应有可见的相对头部运动。
- 禁止用布料模拟、绳索物理或长摆锤去「自动产生生动感」。短绳的稳定来自长度短、驱动有限、阻尼高、默认静止。

## 3. 如何避免悬挂件失稳晃荡（【制作建议】）

短绳本身已降低摆锤效应，但仍可能在转身、低头、平面跟踪抖动时失稳。建议同时采用下列约束（均未实施）：

1. **authored 动画，不自由摆。** 「极慢晃动一拍」做成有限角位移曲线，打满后回到零，并在曲线上做钳制，使任何一帧都出不了 `02` 的安全包络。
2. **高阻尼、无循环闲摆。** 默认静息的目标是静止，不是持续呼吸式晃绳。
3. **平面跟踪抖动过滤。** 头部世界坐标若因 AR 平面或人脸跟踪微抖，固位应跟经过平滑的颅骨，不得把跟踪噪声放大成绳的抖动。【须真机验证】
4. **姿态切换时锁幅。** 外移半步、回蹲、低头压鬃的过程中，绳层角位移建议降到接近零；需要那一拍时，放在动作落稳之后，而不是位移中途叠加。
5. **低头专项。** 晚安低头会改变守结相对眉眼的投影。须单独检查：结不得滑向眉心或眼睛；空隙不得被压成贴额；触点仍点得到守结。必要时在该姿态把绳层锁死。
6. **前倾专项。** 前倾是把重心送回门墩位，不是离地扑出。额饰随头微倾，但仍在中上额可读位置，不得甩出包络。
7. **不做额外配重动画。** 侧豆不单独甩，不靠左右豆「打拍子」。

## 4. 门边蹲守的落位（角色身体，额饰从属）

守绒的着生是四足蹲在门边地面，门墩感来自重量。本包不制作角色身体模型，但额饰稳定以身体落位成立为前提：

- 角色须落在检测平面或屏内同构平面上，Y 轴不靠飘浮制造「守护感」。
- 前倾与靠近都不把四足整体抬离地面。
- 额饰不承担角色的重心表现，不靠甩结或闪灯来补偿身体没蹲稳。

角色身体网格、绑骨与门边落位均【未制作】，须另包交付后与本建议对齐，并【须真机验证】。

## 5. 与静默沟通时长的关系

单段回应约 1.5–4 秒、光一拍即停，是静默沟通共用口径。【制作建议】把「极慢晃动一拍」放进这一段内完成并复位；具体曲线秒数【本草案级建议】，交 UX / 动画定量，【须真机验证】观感是否仍像「安静蹲守」而不是挂件表演。

闲聊只有微光一息、身体不动，故闲聊段不要附赠绳摆。

## 6. 失败态也不许用晃荡或离头来补

跟踪短暂丢失时，不得让额饰停在世界空间中晃，也不得让结离开头部单独漂着。建议随角色一起进入安全静帧或随角色淡出，再在跟踪恢复后以静息姿态出现。此条为【制作建议】，失败策略须与 CIO-AR 对齐，【须真机验证】。不得把失败态做成飘着的守结。

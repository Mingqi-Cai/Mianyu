# 02 · 识别面、清空区与摆动包络

日期：2026-11-12（Asia/Shanghai）  
正本：配饰 `05` 第 3–4 节、`08` 结构示意、`09` 收口  
性质：识别与安全距的结构建议。网格预留与包络数值均为【制作建议】，【未制作】，【须真机验证】。

## 1. 必须外露的识别面（【已锁定】）

硬性清空：眉、眼、鼻、嘴的轮廓必须完全外露。配件不得压眉、挡眼、挡鼻或挡嘴。

| 识别面 | 要求 | 额饰侧约束 |
| --- | --- | --- |
| 眼周 | 眼裂、上睑、下睑、眼角全部可见，供面部 / 角色识别 | 摆动包络与侧豆下沿均不得进入眼周。任何一帧不得拍到眼周 |
| 眉形 | 左右眉的完整形状可见，含眉峰 | 守结下沿与眉峰之间必须留出额绒空带；包络不得越过眉上安全线 |
| 鼻梁 / 鼻头 | 鼻梁与鼻头轮廓外露 | 配件不到达鼻区；前倾或低头时同样不得扫到鼻梁 |
| 嘴部轮廓 | 嘴缝、嘴角外露 | 配件不到达口区 |
| 额饰识别面 | 中央暗金盘长守结仍是第一识别物；近处应能读出短 V 绳 | 结位在中上额，不改造型语言。识别的是守结，不是旅签，也不是贴额圆点 |

固位在鬃毛发际线，避开五官关键点。正面几乎只看到两根细绳从鬃毛中垂出，不出现头箍剪影。

## 2. 面部清空区与眉上安全线（【已锁定】+【已知可保留】）

- **结位**：守结中心高度接近 V3 贴额结，落在中上额，而不是眉心附近。验收改稿已把固位提高、悬绳缩短。
- **眉上额绒空带**：守结下沿到眉峰之间留出一条清楚的额绒空带，宽度足以容纳「极慢晃动一拍」和轻触收光，而不碰到眉毛。
- **眉上安全线**：画在眉峰之上、空带下沿处。守结、侧豆、悬绳在任何一帧都不得越过这条线（见配饰 `08` 侧面标注）。
- **侧豆下沿**：不得超过眉尖，更不得靠近眼裂。
- **不压脸**：守结是悬挂件，背面与额绒之间保留可见空隙，不嵌入、不贴死、不向前压迫面部。

【已知可保留】改稿后空带已经清楚、不再贴眉，但因上方要露出极短悬绳，空带仍略窄于 V3 贴额稿。AR 制作不得为了「加宽空带」把结做大或下移；若再收，只可略提固位或再缩绳。

安全线与空带以角色视觉稿 `02` / `04` 和结构图 `08` 为准，不使用第一版低结稿的线位。

## 3. 摆动包络（【已锁定】口径 + 【制作建议】起算范围）

锁定口径：以固位点为原点，前后左右的角位移都很小；默认静息几乎静止；轨迹不扫过眉眼，不带动身体。额绒空带就是为这一拍微摆预留的。

【制作建议】起算范围（不是已锁定参数，【须真机验证】后只能收紧、不得放宽到越线）：

| 项 | 建议起算 | 硬限制 |
| --- | --- | --- |
| 驱动方式 | 单一 `SR_Acc_CordRoot` 角位移，左右绳保持浅 V | 禁止左右绳独立大摆，禁止布料 / 自由摆锤 |
| 左右角位移 | 建议先按 ±2°–4° 试 | 守结与侧豆任何一帧不得越过眉上安全线，不得离开中上额可读范围 |
| 前后角位移 | 建议先按 ±3°–6° 试，且以不碰到额绒、不冲向镜头为准 | 向前不得缩小到贴脸，向后不得嵌入额绒；保持约 2–4 mm 空隙可被侧视读出 |
| 时间 | 一拍极慢，随后复位静止。不循环闲摆 | 与静默沟通单段节奏对齐的具体秒数交 UX / 动画，见 `04` |
| 静息 | 几乎静止 | 不得用持续微摆制造「活着」 |

包络检验应以固位点为原点，在头部局部空间做角位移包络，并把结果投到眉上安全线、眼周、鼻梁和额绒表面上。低头、前倾等姿态要另出包络，不能只验正视静帧。包络尚未烘焙，也未真机验证。

## 4. 2–4 mm 悬空间隙如何在网格上预留（【制作建议】，【未制作】）

正本设计空隙为约 2–4 mm，不贴死、不压脸。【已知可保留】该空隙在 `03` 角色实稿里仍偏含蓄，须结合 `04` 与 `08` 阅读。AR 网格仍须按 2–4 mm 预留，不得因为二维含蓄就做成贴额死结，也不得为了「更戏剧化」把空隙做得过大、把结推离中上额或挡到识别面。

建议做法（均未实施）：

1. **角色世界尺度尚未锁定。** 2–4 mm 是正本给出的设计空隙，制作时按角色最终世界尺度换算到引擎单位。不得擅自改成视觉上的「看起来有一条缝就行」。
2. **额绒外表面为基准。** 在中上额取一条与守结背面相对的额绒外表面（含毛绒厚度，不是头骨）。守结背面沿面法线向外偏移 2–4 mm 放置。建议默认先落在 3 mm 附近，再在侧视与真机里检查可读性。
3. **守结网格不与额绒做权重混合，不共享顶点。** 结是独立网格，背面保持干净的低凸起，避免穿模。
4. **碰撞 / 安全距。** 在额绒外表面与眉上安全线、眼周盒子之间烘焙不可进入区域，见 `05`。静息、一拍摆动、低头压鬃、门边前倾都要检。
5. **侧视可读。** 近景和侧视应能读出「绳在垂、结在额前」。若真机距离下 2–4 mm 几乎不可见，优先用侧光 / 轻微接触阴影帮助读出空隙，而不是把结前移或放大。此条【须真机验证】。

## 5. 额饰识别与面部识别的分工（【制作建议】，【须真机验证】）

- 面部识别依赖清空区，不依赖额饰。额饰故障或光关掉时，眉、眼、鼻、嘴仍须可识别。
- 额饰作为记忆点，用于「暗金一闪 / 微光一息 / 轻触收光」，以及二维缩小后的「短 V + 中央守结」。
- 风险：暗金反光、局部发光或悬挂件贴近额面，可能干扰人脸 / 角色特征点。【须真机验证】；若冲突，应收敛发光范围或调整检测策略，不得为识别去改结位或挡脸。
- 轻触区域只包住守结，不得做成一块盖住额头的热区。

## 6. 二维缩小仍要成立（【已锁定】要求，【须真机验证】实现）

必须仍能读成「短 V 绳 + 中央暗金守结」，不能退化成贴额圆点，也不能变成一条宽额带或一排流苏。这是造型锁定，也是 LOD 验收项，见 `05`。本包尚未产出任何 LOD 网格。

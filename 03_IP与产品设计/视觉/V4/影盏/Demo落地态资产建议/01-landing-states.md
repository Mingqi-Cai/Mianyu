# 01 · 坐 / 靠 / 蹲落地态

日期：2026-11-12（Asia/Shanghai）  
正本：`behavior/01-影盏-Demo状态表.md` 第 1、6、8 节；`behavior/03-不允许只悬浮的反例说明.md`  
视觉基准：`04-影盏贴墙呼吸光轨.jpg`（已亲自打开对照）  
性质：落地接触的资产建议。三态网格与阴影均【未制作】，【须真机验证】。不得当作已实现的落地能力。

## 1. 默认稳态是坐下（【已确认】）

光影旅伴的默认态是「坐着的影」，不是悬着的灯。先有落点，才有贴墙的影子。

- 落位成功并完成出现之后，收成坐下。
- 靠 / 蹲可用于短切换，Demo 主路径不必巡演三姿。【已确认】坐 / 靠 / 蹲可用；主路径不巡演为【本草案补全】。
- 不站起、不绕场、不把「站」写成影盏默认（「靠窗站」属于阑岚，禁止串戏）。
- 「停留」只是短过渡拍，可跳过，不升成与坐下 / 躲藏并列的官方状态名。资产上不要为「停留」单独立一套骨骼或官方姿态名；至多是坐下之前的短安置（坐实、理好插片轮廓）。

V3 基准可见的默认画面：圆浑的暖琥珀纸灯身体坐在木质台面上，微靠墙，臀部与下摆落在桌面，双腿在身前收着，脚不离桌面；墙上有软阴影；头上插着方形月松镂空片。本包按此写接触面，不改成扁剪影，也不改成离桌悬浮。

## 2. 三态接触面与重心（【已确认】姿态 + 【制作建议】接触）

角色世界尺度尚未锁定。下表描述的是接触关系，不是已锁定的厘米身高。10–15 cm 平移是行为已确认参数，须在尺度确定后换算到引擎单位，见 `03`。

| 态 | 接触面（【制作建议】） | 重心 | 使用场合 |
| --- | --- | --- | --- |
| 坐下（默认） | 主接触：臀部 / 下摆底面与桌面或地面贴合；次接触：后背或后脑勺附近可与墙面有轻微靠触，但不是靠墙把身体挂起来。双足 / 收起的腿仍在承面上，脚不离「地」 | 在坐，不在漂，也不把重量全部交给墙 | 出现后的默认在场、回位后、关麦「先看着」 |
| 靠（短切换） | 仍须保留底面与桌面 / 地面的主接触；靠面（墙）成为更明显的次接触。肩背或后脑可更贴近墙，软阴影在墙上更清晰 | 仍有坐或蹲的垂直分量，禁止变成「吸在墙上的贴片」 | 短切换或躲藏时「仍暗示靠」；不是主路径必演 |
| 蹲（短切换） | 底面接触面积更紧凑（脚掌 / 蹲距与下摆），仍完全在承面上。可贴近墙根，但不离地 | 更低、更收，重心仍在承面以内 | 短切换或墙根藏点的身体暗示；不是主路径必演 |

三条共同红线：

- 每一态都必须有一个可见的水平承面接触（桌面、地面或屏内同构平面）。
- 墙是可选的立面，不是唯一承重。没有墙也能坐，见第 4 节。
- 软阴影必须落在同一承面上（有墙时，墙上可另有一身影）。关掉内透光之后，身体和接触阴影仍在面上。

## 3. 软阴影与底面贴合（【已确认】要求，做法【制作建议】【未制作】）

V3 基准同时有：桌面上的接触感、墙上由身体和插片投下的软阴影。这是重量证明，不是装饰光。

建议（未实施）：

1. **接触阴影（contact shadow）**：紧贴底面接触斑，用来读「坐在这张桌子上」。无立面时它是主要重量证据。
2. **墙面软阴影**：有立面时，身体与头顶插片可在墙上留下软边影子，形状要能读出体积，不要投成一张薄卡片。
3. **阴影先于或同时于身体出现**（行为反例页已写）。不要身体先飘出来再补影子。
4. **阴影打在检测平面 / 墙的世界表面上**，不要只做一圈假的屏幕光环来代替落地。落点环若共用壳已有，只能作辅助，不能替代接触阴影。【本草案补全】用法。
5. **躲藏半透明时，阴影跟着减弱，但不先于身体消失成「空中一团光」。**

底面贴合：坐下网格的底面应有一段相对平整或可略压进平面的接触区，避免只有一个点磕在桌沿上、或底面是圆的而看起来在滚。不要用向下的持续动画「往下坐穿」来假装重量。全部【未制作】，贴合精度【须真机验证】。

## 4. 无立面时的桌面落点（【已确认】已采纳）

只有桌面、没有立面时，仍坐在桌面上，用软阴影和坐姿建立重量，禁止上浮补「灯感」。需 AR 真机验证，但不回退为悬浮方案。

资产含义：

- 坐下网格必须在「身后无墙」时仍然成立，不能把重心或绑定依赖写成「必须有墙才坐得住」。
- 无墙时取消墙面阴影即可，保留桌面接触阴影。
- 不得为了找回 V3 那张「贴墙侧影」而把角色抬离桌面、或改成面向镜头的悬挂灯。
- 靠近在无墙时改为沿桌面水平短移，仍脚不离面、Y 轴不上浮，见 `03`。

## 5. 手里盆栽与墙根光轨（视觉从属，不另立状态）

V3 基准图里，影盏双手捧一棵很小的盆栽，墙根有一条暖色光轨。本包作如下边界，避免扩成新的官方系统：

- **盆栽**：视为 V3 默认视觉道具，帮助读出体积与坐姿（手在身前、物在掌中）。不是新的官方状态，也不自动变成必须可交互的道具系统。是否在 Demo 网格中保留，随角色视觉正本；本包建议保留以对齐 V3，但不为它单独立状态名。
- **墙根暖色光轨**：视为场景 / 落点线索，对应「墙根光边」藏点意象，不是角色必须携带的一条会移动的灯带。角色平移时，光轨不必作为身体附件跟着走；它属于环境或落点装饰，须与 CIO-AR 场景方案对齐。【制作建议】

掌心 / 边缘可关光是已有光效接口，不要和盆栽或光轨混成一个零件。

## 6. 验收一句

关掉所有光效之后，影盏是否仍然坐在一张桌子或一块地板上？如果关掉光它就「没了」或还在半空，就是只做了悬浮。本条来自行为反例页，本包把它当作落地态资产的第一验收句。当前模型【未制作】，此句尚未可验。

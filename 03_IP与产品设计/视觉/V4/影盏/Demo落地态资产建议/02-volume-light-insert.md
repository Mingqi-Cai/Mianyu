# 02 · 体积、内透光与插片

日期：2026-11-12（Asia/Shanghai）  
正本：行为表第 5.3、5.4 节；反例页「白纸扁剪影」条；故事中的插片内容包口径  
视觉基准：V3「贴墙呼吸光轨」——暖琥珀纸灯质感、圆浑身体、头上方形月松镂空插片逆光、闭目  
性质：体积与插片接口建议。网格、材质、内容包均【未制作】。轮廓溶换属【本轮故事与 Demo 的执行默认】，不是已立项锁定，也不是用户已拍板。

## 1. 如何避免白纸扁剪影（【已确认】红线）

V3 已明确要回到暖琥珀内透光坐姿 + 木质落点。不合格的做法包括：一张被钉在空中或墙上的白纸人、无厚度的侧影卡、只靠外轮廓发光、没有内透的实心石膏白。

【制作建议】（未实施）：

| 项 | 做法 | 不要做 |
| --- | --- | --- |
| 体积 | 圆浑的灯体：头、胸腹、收着的腿和手都有厚度；纸纹与折痕在三维上成立 | 单面片、纸板切割人、纯法线假厚度 |
| 材质 | 暖琥珀纸灯：可透光的纸质，可见细裂纹 / 纤维，色是暖琥珀，不是复印白纸 | 纯白自发光壳、金属灯、塑料夜灯 |
| 内透光 | 光从身体里面透出来，边缘和掌心 / 身体体积一起被照亮；强度可关 | 只用外描边光或屏幕 bloom 代替体积 |
| 插片 | 头上有真实的槽，方形片插进去，镂空被体内的光照亮（逆光） | 把插片画成脸，或把插片当贴在额上的贴花 |
| 阴影 | 身体和插片都能投下软阴影，证明占空间 | 关掉光以后人消失，或影子是一张纸的边 |

闭目是身体上的安静图形（V3 为两个深色闭眼），不是闲聊时的表情包通道。闲聊改的是插片镂空的明暗，不改变这张闭着的「脸」。

## 2. 插片槽与内容包（【已确认】记忆点 + 【制作建议】结构）

插片是内容包，不是衣柜换装，不是表情滑条，不是一张新脸。开放槽的长期关系靠更换插片变熟，不靠学会说话或离地更近。

建议结构（【未制作】）：

```
身体体积（暖琥珀内透光）
 └─ 头顶插片槽（凹陷的真实槽位，不是空气里的挂点）
     └─ 当前插片卡（可替换内容）
         ├─ 卡面 / 背
         ├─ 镂空遮罩（被体内光照亮）
         └─ 镂空眼参数（明暗，最多交替 2 次）
```

- 槽在头顶，方形，深度足够让插片「插着」而不是漂在头皮上。V3 基准是竖直插在头顶开口中。
- 默认内容对齐 V3：松树 + 弯月镂空。这是视觉基准，不是唯一永远不可换的内容；但 Demo 若只做一张，就先做这一张，不要改成无关图形。
- 图形须全原创几何。禁文物同款 / 正宗非遗宣称。（故事红线，制作时遵守。）
- 插片更换是换内容参数 / 换卡，不换身体网格，不换脸部形态。

故事层提到开放槽三件套——插片（主）、姿态底座、掌心可关光。本包只把插片槽和掌心 / 边缘可关光写成资产接口；坐 / 靠 / 蹲的接触按 `01` 写，不把「姿态底座」扩成可滑动的姿态库，也不把三件套升成新的官方状态机。

## 3. 插片资产接口（参数，不是换脸）

下列接口都是【制作建议】，运行时尚未实现。

| 接口 | 用途 | 约束 |
| --- | --- | --- |
| `insert_id` / 内容包标识 | 当前插在槽里的内容 | 换 id 不等于换脸或换一套身体 |
| 镂空遮罩 | 决定哪些区域被体内光照亮 | 闲聊只改变这些区域的明暗，不变形体网格 |
| `cutout_eye_gain`（名称可调） | 闲聊：当前插片镂空眼明暗交替 2 次 | 【已确认】次数与「不是表情包」的红线。两拍后停，约 1.5–4 秒 |
| 边缘呼吸光 | 确认时半拍；靠近时只呼吸半拍；线索极淡 | 一拍即停。不做追光秀、持续扫光、闪光雨 |
| 体内基础透光 | 坐下时维持可识别弱光 | 可关。关光后身体体积与落点仍在 |
| 掌心 / 边缘光 | 可关；晚安或结束时渐灭 | 见下方收尾层级，勿与一次轻互动抢同一拍 |

闲聊动作【已确认】：身体基本不动；当前插片镂空眼明暗交替 2 次。寻找或靠近时原「观察」动作并入闲聊复用，不另立状态名，不改变坐实，不做人体跟随，不读「我在看你」。

## 4. 插片确认 / 轮廓溶换（【本轮故事与 Demo 的执行默认】）

找到后一次轻互动走「插片确认 / 轮廓溶换」（可跳过）；晚安或用户点结束时关光。两拍不抢在同一收尾里同时做完。

**这是 Design 第一次验收建议的默认写法，不是已立项锁定，也不是用户已拍板。** 正式锁定仍须用户在 CIO 窗口确认；财务底稿继续标待立项，不覆盖那一页。本包按此默认预留资产接口，但不把溶换写成已锁定官方设定，也不把未制作的溶换 shader 写成已实现。

【制作建议】预留（全部【未制作】，且该项整体仍属执行默认，不是已锁）：

- **插片确认**：坐正已在身体层完成的前提下，让当前插片轮廓或镂空被强调一次（短、可关），不爆闪，不换脸。
- **轮廓溶换**：在同一槽位里，从当前插片轮廓过渡到另一张内容包轮廓，一次即可；用遮罩 / 透明度 / 内透光交接，不用切镜头，不做换装表演。
- 溶换内容若 Demo 尚未选定第二张插片，接口先留空位，不得临时用表情包或随机贴图顶上。
- 关光留给晚安或结束：掌心 / 边缘光渐灭，身体仍坐在落点上静帧。

## 5. 光与体积的验收关系

- 灯感用暖琥珀内透光和一拍即停的边缘呼吸光完成，不用 Y 轴上浮。
- 可关项：掌心 / 边缘光可关；溶换可关；关光后必须还能看见坐着的身体和接触阴影。
- 远距离保持坐实轮廓可认，光更弱；近距离减弱闪烁次数，避免「被盯」。这些距离变化属【本草案补全】，光的实现【须真机验证】。

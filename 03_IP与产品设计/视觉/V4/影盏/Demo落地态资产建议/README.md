## 已锁定要点（不得改）

- 默认坐 / 靠 / 蹲，禁止只悬浮；Y 轴不上浮。
- 默认稳态是坐下。靠 / 蹲可用于短切换，主路径不必巡演三姿。
- 暖琥珀内透光侧影 + 插片；禁白纸扁剪影。
- 靠近 = 坐姿贴墙平移 10–15 cm，脚不离「地」。
- 确认 = 坐正 1 拍 + 边缘呼吸光半拍。
- 闲聊 = 当前插片镂空眼明暗交替 2 次（换插片参数，不是表情包）。
- 躲藏 = 墙根光边，身体仍暗示坐或靠；预设偏移 + 淡出 / 半透明，不做真家具遮挡。
- 无立面时仍坐在桌面，用软阴影建立重量，禁止上浮补灯感。
- 失败 / 拒相机走屏内同构，不能改回悬浮方案。光一拍即停。

# 05 · 制作准备与自检

日期：2026-11-12（Asia/Shanghai）  
性质：制作准备。下列规格均为【制作建议】。模型、光、动画、插片均【未制作】，完成后仍【须真机验证】，不可当作已可上线。

结构示意见同目录 `06-landing-contact-volume-light.svg` / `.png`。该图仅为示意，不是已做好可上线模型，不替代 V3 基准图，也不替代行为正本。

## 1. 拓扑与姿态（【未制作】）

- 身体按 V3 基准做圆浑纸灯体积：头、身、收着的腿与手皆有厚度。闭目图形画在头上，不是一套表情 morph 主通道。
- 默认姿态是坐下，底面有可贴合桌面 / 地面的接触区。微靠墙是次接触，可在坐下姿态里略向后靠，不必先做一套完全离墙的「悬空坐」。
- 靠 / 蹲：优先用同一身体的短切换（小幅度姿态或两到三套静止造型），不要做成可连续滑动的姿态库，不要进 Demo 主路径巡演。无论哪一态，底面接触不能丢。
- 头顶做真实插片槽；默认插月松方形镂空片，片是独立可替换网格。
- 双手位置对齐 V3：可捧一棵很小的盆栽作为视觉道具，不另立状态机。
- 不要做飞行骨架、悬浮根骨或「灯挂在空中」的备用网格。

## 2. 材质、内透光、插片（【未制作】）

- 暖琥珀可透光纸质，带细裂纹 / 纤维，不是白纸，不是塑料夜灯。
- 体内有可关的暖内透；边缘呼吸光与掌心光单独可控，默认一拍即停。
- 插片镂空被体内光照亮（逆光）。闲聊只调镂空明暗参数，两次后停。
- 轮廓溶换若按本轮执行默认制作，用槽内遮罩交接，不做换脸；该项不是已立项锁定，也不是用户已拍板，可关。
- 关光后纸质体积、插片轮廓和接触阴影仍在。禁止「光就是身体」。

## 3. 阴影与落点（【未制作】）

- 必做桌面 / 地面接触阴影。有墙时加墙面软影（身体 + 插片）。
- 出现时阴影先于或同时于身体。
- 无立面只保留桌面接触阴影，不得用上浮或更强自发光补「灯感」。
- 屏内同构也要有可见平面上的接触阴影或淡落点环，不能只靠中心发光。

## 4. 动画限制（【未制作】）

- 根运动贴面，Y 相对承面锁定。
- 出现：淡入 + 坐实，无坠落、无 Y 向落下曲线。
- 靠近：切向 10–15 cm（按最终尺度换算），无抛物线、无放大扑出。
- 躲藏：同平面滑向预置偏移 + 透明度，不向上隐去，不飞向镜头。
- 回位：原路滑回再坐正，不瞬切实体化。
- 确认坐正 1 拍后回安静坐姿。闲聊身体基本不动。
- 禁止循环表演、持续扫光、姿态滑条、表情包。
- 「停留」「观察」不作为官方动画状态名出现在片段命名里。

## 5. 建议制作顺序（不是已排期承诺）

1. 坐下阻塞模：接触面、微靠、插片槽、与 V3 轮廓对照。关掉所有自发光，检查是否仍坐在面上。
2. 无墙桌面和短切靠 / 蹲的接触检查。
3. 内透光与阴影（桌面 + 墙）。
4. 插片默认内容与镂空明暗参数。
5. 贴面移动、出现淡入、躲藏半透明（Y 锁）。
6. 按执行默认预留溶换与关光接口，但不把该项写成已锁。
7. 与 CIO-AR 对齐后真机验证，含屏内降级。

任何一步完成都不等于「已可上线」。

### 后续若进入制作（当前全部未勾，均为【未制作】）

- [ ] **关掉所有光效后，身体是否仍坐在桌子或地板上？** 若关掉光就「没了」或还在半空，不合格。
- [ ] 出场未从天而降、未瞬切在半空；阴影先于或同时出现。
- [ ] 坐下底面贴合成立；无立面时仍坐在桌面，未上浮补灯感。
- [ ] 靠近只有贴面短位移，无 Y 轴上浮、无放大扑出；真机量感接近 10–15 cm。
- [ ] 躲藏仍能读出坐或靠，不是墙中或空中的剪纸；未做真家具遮挡。
- [ ] 身体是暖琥珀体积 + 插片槽，不是白纸扁剪影。
- [ ] 闲聊只改插片镂空明暗 2 次，不换脸。
- [ ] 光一拍即停；关光后体积与落点仍在。
- [ ] 屏内降级同样有落点与接触阴影，不是中心悬浮。
- [ ] 微信小程序 AR 真机验证：平面、无墙、弱光失败、Y 锁、阴影。
- [ ] 仍不得称为已可上线，除非 Design / CIO-AR 按当时流程另作发布验收。

# 03 · 贴面运动与 Y 轴锁

日期：2026-11-12（Asia/Shanghai）  
正本：行为表第 4–6 节；反例页第 2、4 节  
性质：运动平面与失败降级的资产建议。动画与平面跟随均【未制作】，位移尺度【须真机验证】。不得当作已实现的运动系统。

## 1. 总则（【已确认】）

只允许沿平面或沿墙的水平 / 贴面移动，不允许作为主运动的垂直升起。Y 轴不上浮。脚不离「地」。位移慢而短。光一拍即停。

「地」指用户点按的桌面、地面，或墙边木质落点；无立面时就是桌面；失败时是屏内同构的可见平面。不是空气中的隐形地板。

角色世界尺度尚未锁定。靠近平移 **10–15 cm** 是已确认的行为参数，制作时须按最终世界尺度换算，并在真机上量是否仍是「并排坐近一点」，而不是飞近或几乎不动。

## 2. 出现：落点淡入（【已确认】+【本草案补全】）

- 在用户点按的落点上直接淡入，先有软阴影和坐姿，再进入短暂停顿或坐下。出现 ≤3 s。【已确认】
- 不瞬切、不从天花板掉下、不从空中落入。
- 短暂停顿即「停留」：已经在落点上，由「刚出现」收成坐下，允许一次很短的安置（坐实、理好插片轮廓），全程贴面。【本草案补全】；不升为官方状态名。时长交 UX 定量。
- 资产要求：出现动画只有透明度 / 存在感与轻微坐实，没有 Y 向位移曲线。阴影先于或同时于身体出现。

## 3. 靠近：贴面平移 10–15 cm（【已确认】）

- 坐姿贴墙平移 10–15 cm，脚不离「地」；沿墙意象面轻轻滑近，不上浮、不跳、不扑镜头。
- 光只呼吸半拍，不做追光秀，不扫光带路。
- 位移向量贴面，不走抛物线，不用放大模拟靠近。
- 无立面时改为沿桌面水平短移，规则相同。
- 近距离最多「坐正 1 拍」表示察觉，随即回安静坐姿，不把靠近做成冲镜。

【制作建议】：身体根骨骼只在承面切向移动；Y 对承面的相对高度锁死。靠墙时沿墙切向滑，保持底面接触。全部【未实现】。

## 4. 躲藏：贴面滑向墙根（【已确认】藏点 +【本草案补全】滑移写法）

- 藏点意象：墙根光边（禁飘）。主线索：插片轮廓 / 呼吸光。
- 用相对落点 2–3 个预设静音偏移 + 淡出 / 半透明，**不做**真家具遮挡。
- 沿墙或沿平面滑向偏移点，同时降低不透明度 / 边缘光，像影子被挪到墙根，而不是物体被删除。
- 藏住时仍贴面，脚不离「地」，Y 轴不上浮。身体仍暗示坐或靠，不要变成飘在墙中的剪纸。
- 坐下→躲藏的过渡建议 1.5–3 秒，【本草案补全】，供 UX 定量。无倒计时。
- 不是向上隐入天花板，也不是向镜头飞来再消失。

【制作建议】：偏移点是同一承面上的预置坐标，不是世界空间里的悬浮点。半透明时接触阴影一起减弱。无墙时，偏移仍在桌面平面上朝「远离主视但仍在面上」的位置滑，不得改成下沉或上浮消失。

## 5. 回位坐正（【已确认】）

- 反向滑回落点并抬回存在感，再坐正。禁止「啪」地出现在镜头前，禁止突然实体化。
- 随后可接一次轻互动（可跳过；本轮 Demo 为插片确认 / 轮廓溶换，层级见 `02` 与 `04`）或直接静帧。
- 坐正是身体姿态的 1 拍，不是离地再落下。Y 仍然锁在承面上。

## 6. Y 轴锁（【已确认】红线 +【制作建议】实现）

| 允许 | 不允许 |
| --- | --- |
| 沿桌面 / 地面水平移动 | 把角色抬离承面补「灯感」 |
| 沿墙切向滑（靠墙时） | 从天而降、抛物线跳近、升到人脸高度打招呼 |
| 坐下、坐正、短切靠 / 蹲时，接触面之间的极小高度变化（仍贴面） | 以垂直升起作为主运动 |
| 屏内同构平面上的同样贴面运动 | 丢平面后改挂到屏幕中心或镜头前漂着 |

【制作建议】在根运动上加一条相对承面的高度约束，动画曲线不含作为主运动的向上位移。跟踪抖动时平滑，但平滑不得表现为「先浮起来再放下」。【须真机验证】弱光、斜桌面、平面抖动时这条锁是否还成立。

## 7. 屏内降级仍须有落点（【已确认】）

拒相机、超时、弱光丢平面一次、机型不支持，均走屏内同构玩法：在模拟平面或暖雾底上点按落位，状态机与 AR 主路径相同。不能改回悬浮方案。

不正确：AR 丢平面后把影盏改挂在屏幕中心或镜头前漂着「先撑住」。  
正确：失败一次即降级屏内，角色仍被「放下」在一个可见平面上，带软阴影或淡落点环。

弱光成功率尚未真机验证，但不能用悬浮当备用方案。Demo 不做真家具遮挡、人体跟随、暗房满血 6DoF、姿态库 / 表情滑条——这些缺失不构成「只好悬浮」的理由。

屏内同构的平面、暖雾底和落点环属壳 / CIO-AR 能力，本包只要求：降级后的影盏资产仍是坐下的暖琥珀体积，仍有接触阴影，仍走同一套贴面运动，不得另做一套悬浮网格。【制作建议】【须真机验证】【未制作】。

## 8. 运动与命名纪律

出现后的短安置、回位后轻互动前的停顿，在动画上可以存在，但文档、骨架和状态机注释都不要把它们写成官方状态「停留」。闲聊里的极小转向或插片明暗，不要写成官方状态「观察」。

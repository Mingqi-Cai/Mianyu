## 4. 与 UX

单段约 1.5–4 秒、可跳过、可关麦、可关光、可离开，【已确认】。停留与部分过渡秒数【本草案补全】，时长仍交 UX 定量。本包不擅自锁定这些秒数。

关麦「先看着」：静坐在场，无语音采集；落位、躲藏、点找、「算了」、回位、一次轻互动全部不依赖开麦。【已确认】

文案与标签红线由行为正本约束：不输出助眠、疗效、情绪诊断等。资产与光效命名避免「安神灯」「助眠呼吸」之类。

## 5. 分列汇总

### 已确认（本包不得改）

默认坐下（可短切靠 / 蹲）；禁只悬浮；禁白纸扁剪影；Y 轴不上浮；靠近贴墙 10–15 cm 且脚不离地；确认坐正 1 拍 + 边缘呼吸光半拍；闲聊插片镂空眼明暗 2 次；躲藏为墙根光边 + 预设偏移与半透明、不做真家具遮挡；无立面仍坐桌面；失败走屏内同构、不能改回悬浮；光一拍即停；出现 ≤3 s、不从天而降；命名上不把停留、观察升成官方状态。

### 本草案补全（不是已锁定官方设定）

出现后短安置的写法与建议秒数；主路径不巡演三姿；躲藏滑移过渡建议 1.5–3 s；距离远近的光强变化；落点环的辅助用法；关麦复用确认动作的方式。须经 Design / UX / AR 验收，本包只按行为表预留。

### 本轮故事与 Demo 的执行默认（不是已立项锁定，也不是用户已拍板）

找到后一次轻互动用「插片确认 / 轮廓溶换」；关光留给晚安或用户点结束。正式锁定仍须用户在 CIO 窗口确认；财务底稿继续标待立项，不覆盖那一页。本包只预留接口，不把溶换特效写成已实现，也不把该项标成【已确认】。

### 制作建议（尚未实施，可在验收后微调）

接触面划分、接触阴影与墙影做法、插片槽层级与参数名、单一 Y 锁约束、无墙时的桌面短移、屏内同构仍用同一套坐下网格、盆栽作为 V3 视觉道具而不另立状态、墙根光轨作为环境线索而不是身体附件。

### 须真机验证 / 待锁

弱光与斜面下的平面检测；10–15 cm 在真机中的可读距离；软阴影打在真实表面上的质量；无立面坐下的稳定性；插片镂空明暗在不同曝光下是否像表情包；丢平面降级是否干净；角色世界尺度。轮廓溶换是否采用，待 CIO 窗口确认，本包不锁死。

### 未制作 / 未实现

影盏身体与插片的三维模型、三态网格或姿态切换、材质与内透光、软阴影方案、贴面动画、溶换效果、小程序资源与真机包。本接口表不是已上线 API。

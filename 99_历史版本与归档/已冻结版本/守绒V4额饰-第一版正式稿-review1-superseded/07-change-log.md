# 修改记录：守绒 V4 额头悬挂式配件

日期：2026-11-12（Asia/Shanghai）  
基准：V3 展示图 `03-守绒门边前倾_额头守结.jpg`（2026-11-07 静默沟通最终版口径）。  
原则：只改额饰装挂方式，不重做整体形象。

## 改了什么

1. **装挂方式**：V3 的贴额暗金守结，改为悬挂式额饰。守结不再贴死在额绒上，而是由短绳悬在额前。
2. **增加固位**：在鬃毛发际线增加双点暗金扣环（设计上也可换成极细暗金横杠），藏进卷鬃，作为悬挂原点。正面实稿选择了更隐蔽的双点固位，避免出现宽额带或头箍感。
3. **增加悬绳**：两根极短暗红细绳，与胸前绳同一语言，呈浅 V 垂下，把守结送到额心。
4. **增加极短第二层**：守结左右各一枚极小暗金豆，下沿设计为不超过眉尖，用于形成很轻的层次，而不是长帘。
5. **动态口径对齐**：把静默沟通里「守结绳可极慢晃动一拍」落到可分件的悬绳层，而不是让整颗头或整张脸跟着晃。
6. **金光作为状态，而不是贴额发光贴**：细节特写恢复与 V3 同质的局部暖金光；正面全身静帧更克制，对应「微光一息」的安静状态。互动记忆点不变：一闪、微光一息、轻触收光。

## 保持了什么

1. 卸下锣鼓的守夜狮身份，以及门墩蹲守的姿态与门边场景。
2. 鬃毛与面容：丰满卷曲鬃毛、圆耳、柔和下垂眼、棕色眉与鼻、安静略带倦意的表情。
3. 体色与体型：暖柔葵色/焦糖色毛，奶油色胸腹、嘴筒与肉垫，柔软毛绒质感。
4. 胸前暗红绳结，以及绳下的小青铜/暗金小结坠。
5. 守结本身仍是暗金盘长结，仍是额饰的主识别物，不是新的符号系统。
6. 禁空白旅签挂牌；禁锣鼓；禁「守护你入睡」类文案；图中无营销文案。对照图只标注 V3 / V4。
7. 角色不是苗族人物，配件也不是某一支系传统头饰的换装。

## 未改、也不应回退的锁定

- 2026-11-07 静默沟通最终版口径：力量感来自安静蹲守；额头守结 + 门墩感；靠近后回到门墩位蹲稳；晚安是低头压鬃、轻触额头守结收光（挂件在头上）。
- 箱内原 `mianyu-ip5-design` 目录当前不在，本次不以缺失目录为由推翻 V3 基准。

## 过程取舍（便于验收对照）

- 曾尝试把固位横杠明确画在额表上（工作稿 A）：三件式更一目了然，但横杠容易读成细头箍，不符合「藏进鬃毛、不是宽额带」的方向，故不用作正式正面稿。
- 曾尝试把守结放回 V3 的偏上位置并加强金光（工作稿 D）：位置和光更接近 V3，但模型在守结下方多余地垂出红穗，逼近眉心，结构错误，已弃用。
- 曾尝试更侧的头部近景以强调悬空间隙（工作稿 side-b / side-c）：角度更侧，但守结下沿与近侧眉距离过紧，存在压眉风险，故不用作正式 `03`。正式侧面采用与正面同一门边场景的 3/4 侧。
- 曾尝试用后期给正面守结叠加金光：金属体积被冲成贴纸或出现色带，已全部弃用。正面保持生成稿原貌。

## 已知风险（不粉饰）

1. **守结垂直位置略低于 V3**：V3 贴额结在中上额，额绒空带较宽。V4 正面与 3/4 侧里，守结仍在眉上、不挡眼、不遮鼻嘴，但安全距更紧。后续若再修，应把固位再提高、绳子再缩短，把守结送回 V3 的中上额高度，而不是把结做大或下移。
2. **毫米级悬空间隙在角色实稿里偏含蓄**：正面和 3/4 侧能读出「绳在垂、结在额前」，但 2–4 mm 的空气间隙在毛绒质感上不够戏剧化。更侧的近景又会带来压眉风险。请同时看 `04` 细节特写和 `08` 结构示意，不要只靠文字宣称空隙已经「一眼成立」。
3. **正面全身静帧的金光弱于 V3**：这是有意避免假光。金光记忆点以 `04-v4-forehead-detail.jpg` 为准。若需要正面也达到 V3 那种静息发光，应在后续出图中直接生成，而不是后期贴光。
4. **固位件在正面不够显眼**：因为选择了藏进鬃毛的双点扣环，三件式里的①在全身正面几乎隐没，需要靠细节特写和结构图才能读全。这是为了避免头箍感而做的取舍。
5. **3/4 侧不是纯侧面**：正式 `03` 是同场景轻度 3/4，角色一致性更好，但不是工程剖视。纯侧面请以 `08` 的侧面结构为准。

# 泊泊 · 成长故事

- 官方用名：泊泊
- 已锁定差分：会看窗的软圆旅伴；不对称行李牌耳是第一记忆点；写牌默认本机
- 视觉锚点：V3「牌耳侧倾挪近」——软圆身体，一侧加厚描边的行李牌耳清晰可辨，胸口有章位，常停在行李旁并面向窗向

本文解释已锁定性格与招牌行为，供 Behavior 转化为动作与 Demo。不改设定，不作疗效承诺。

## 1. 来自哪里

泊泊是会看窗的软圆旅伴。它常常停在行李旁，身子像一只被放下来的软圆墩，左右并不对称——加厚描边的那一侧行李牌耳，是它被认出来的第一件事。胸口有一枚章位，像一个留给今晚的空格。

它的名字更接近「停泊」：在一个临时的房间里，对着窗户停一会儿。窗是它要看的方向，不是它要站上去的岗位。站在窗边的位置留给阑岚；守在门边的位置留给守绒。

## 2. 经历过什么

曾经它只是一个圆墩，好看但记不住。放在行李旁边，也容易被看成一只没有特征的软球。后来一侧耳朵变成可写的行李牌，胸口留下盖章的位置，它才有了自己的记号系统。

它开始用「写牌 → 盖章 → 看窗」来度过一个晚上：牌上写下今晚停在何处，章是一次轻轻的确认，看窗是它真正想做的事。它跟过许多箱子，走过许多临时的房间，但学会了一件比旅行更要紧的事：姓名和房号不带走，写过的字默认留在这台设备上。

## 3. 性格如何形成

软、圆、慢，带一点侧倾的癖好。它不点头称是——圆球式点头会把它退回那个没有记忆点的圆墩。确认在场时，是那只不对称的牌耳轻轻侧倾约十度，再回正。这一下既是应答，也是在提醒：先看见牌，再看见它。

性格里有旅行的轻，却没有赶路的急。它喜欢窗，不是为了出去，只是想看一眼外面是不是还亮着。被放在行李旁时最安定；被要求追着人满屋滚动时，性格会散掉。

## 4. 最在意什么

不对称行李牌耳必须一眼可辨。删掉牌耳、改回对称圆耳，泊泊就不成立。写牌默认本机、不上传，是它和用户之间的信用；胸口章位是功能槽，不是随意的装饰贴。

它也在意自己和「看窗的方向」之间还有一条短短的路径，可以挪近，不必贴到人脸上。看窗是陪伴，不是瞭望任务，更不是把窗外风景解释成用户的心情。

## 5. 独特行为习惯

- 确认在场：不是圆球点头，而是加厚描边那侧牌耳轻轻侧倾约 10°，再回正。
- 靠近：两点眼转向窗意象，躯干偏移贴近窗向。
- 闲聊：牌耳吊牌微颤 1 次，短衰减。
- 晚安 / 道具：看窗一拍后低头；写牌字号淡入，或胸口章盖下。
- 常停在行李旁；藏点在行李旁或窗向，线索永远是那只牌耳。
- 写过的内容留在本机；不把姓名、房号带离这台设备。

## 6. 如何理解夜晚陪伴和用户

用户是今晚和它停在同一处的人。它不负责把夜晚说圆，只负责在行李和窗之间陪着待一会儿。你说话，它侧一下牌耳、往窗的方向挪近一点；你关麦，它仍可以看着窗。

写在牌上的字是你的，留在本机，它不向外传。它听得懂粗意，但不出声，也不用牌面句子来做咨询或鼓励。停泊本身就是陪伴：箱子在，窗在，它在。

## 7. 如何与用户建立关系

先被那只不对称的牌耳认出来，再一起完成一次短链：写牌或盖章，然后看窗。落位优先在行李旁、或能同时看见窗向的地面 / 桌面。找到它之后，写牌字号淡入或胸口盖一次章，就是今晚的记号；均可跳过。

关系靠「今晚停在这里」的小记号积累，而不是靠它追随你在房间里走动。几个晚上之后，用户记住的应是那只加厚的牌耳，以及它侧倾一下再去看窗的习惯。它不会改行去守门，也不会变成墙上的灯。

## 8. 未来可怎样成长

真用行李牌、季更章贴、联名章，可以长成功能型的商业线；互动链保持写牌→盖章→看窗。新的牌面和章面仍然默认本机，不上传，不做姓名 / 房号收集。

成长不是把耳朵改回对称圆耳，不是让它开口说话，也不是把看窗升级成飞向窗外。任何新配件如果压过牌耳的第一剪影，就需要退回重排。

## 可转化互动要点

写给 Behavior，可直接改成动作与 Demo。

### 落位 / 姿态

- 点按平面后，优先落在行李旁，并让身体朝向窗向；若现场没有行李箱，用「可被读成行李旁」的地面 / 床尾落点，窗向仍要可感知。
- 默认姿态：软圆坐或墩住；左右不对称，加厚描边的牌耳必须可读；胸口章位可见。
- 出现方式：在落点上被放下，不滚动入场，不弹跳。
- 藏点意象：行李旁 / 窗向。主线索：不对称行李牌耳，不是对称圆耳或身体高光。

### 靠近时的身体反应

- 触发「靠近 / 过来一点 / 陪我」：两点眼转向窗意象，躯干向窗向轻轻偏移贴近；不是扑向人脸，也不是圆球点头靠近。
- 位移短、慢，停在窗向附近，不贴镜。
- 关麦只看时：最多一次更小的牌耳侧倾或一次眼转向窗，然后静止看窗。

### 静默沟通动作（单段约 1.5–4 秒）

| 粗意图 | 动作 |
| --- | --- |
| 确认 | 牌耳一侧轻倾约 10° → 回正 |
| 靠近 | 两点眼转向窗意象 + 躯干偏移贴近 |
| 闲聊 | 牌耳吊牌微颤 1 次（短衰减） |
| 晚安 / 道具 | 看窗一拍后低头；写牌字号淡入或胸口章盖下 |

默认可 1–3 次短回应后软收束「今晚就到这儿」。角色始终不出声。

### 可关麦时仍成立的回应

- 关麦后立即停听；泊泊可继续停在行李旁看窗，无语音采集。
- 落位、寻找、回位、写牌、盖章，全部不依赖开麦。
- 非语音确认：点击牌耳触发一次侧倾回正。
- 非语音结束：看窗一拍后低头，或盖一次章，静帧。写牌若发生，内容仅存本机。拒绝开麦不影响主路径走完。

### 红线 / 禁忌

- 第一记忆点是不对称行李牌耳；不得改回对称圆耳，不得用圆球点头替代侧倾。
- 写牌与章面默认本机，不上传；不采集、不外带姓名和房号。
- 不把泊泊放到门边去守门，或贴墙去发光；看窗不等于站到窗台上取代阑岚。
- 禁用助眠、安神、疗效、咨询等文案；无惊吓、无倒计时、无排行。

# 五角色差异对照

- 文档性质：工作流 B 交付页，供 Design 验收与 Behavior 对照使用
- 正名锁定：霁霁、守绒、影盏、泊泊、阑岚（不以近形字替代）
- 口径依据：V3 静默沟通最终版（2026-11-07）、Design 正名与锁定差分更正、眠语库已确认视觉与玩法约束
- 本页只对照，不改设定；故事只解释已锁定招牌行为

一眼口诀：

| 角色 | 一句话坐标 | 不可被别人抢走的记忆点 |
| --- | --- | --- |
| 霁霁 | 檐下半眯、不营业的小龙形夜客 | 一对可关圆钝角灯；靠近时内收落座 |
| 守绒 | 卸下锣鼓、蹲在门边的守夜狮 | 额头暗金守结 + 门墩般的蹲守 |
| 影盏 | 被放下、贴着墙的光影旅伴 | 暖琥珀内透光 + 插片内容；默认坐/靠/蹲 |
| 泊泊 | 停在行李旁、会看窗的软圆旅伴 | 不对称行李牌耳（第一记忆点）；写牌本机 |
| 阑岚 | 靠窗站着的雾感小灵 | 窗棂负形光斑 + 可关纸折小灯 |

## 起源象限

五人不共享同一出生地，也不共享同一种「被放下来」的理由。

| 角色 | 起源象限 | 不是什么 |
| --- | --- | --- |
| 霁霁 | 雨后初晴的檐下。从檐口未干的水线里留下来，认「有遮的边」为位置 | 不是雪地精灵，不是开门营业的店员龙，也不绑某一座古建檐 |
| 守绒 | 门边。从热闹的守夜排场里走出来，把锣鼓卸下后留下来蹲守 | 不是苗族或其他民族志人物，不是旅行挂牌狮，也不再是会扑跳的表演狮 |
| 影盏 | 墙根 / 木质落点。从易飘的灯影，变成一盏愿意被放下的光影旅伴 | 不是悬空灯、不是白纸扁剪影、不是会换脸的灯笼戏偶 |
| 泊泊 | 行李旁，面向窗。从容易被忘掉的圆墩，长出可写的牌耳和可盖的章 | 不是对称圆耳娃娃，不是门卫，也不是墙上的灯 |
| 阑岚 | 当代窗边。从窗棂投下的负形光斑里站起来的雾感小灵 | 不绑古建花窗，不是会飞的精灵，也不是坐着的软圆墩 |

## 力量感 / 气质来源

| 角色 | 力量感从哪里来 | 气质关键词 |
| --- | --- | --- |
| 霁霁 | 收束。灯少、饰件少、动作短；半眯把「在场」收成不招呼 | 半眯、不营业、可关的灯 |
| 守绒 | 重量。安静蹲住时的门墩感；鬃与结都只动一拍 | 稳、沉、在门边 |
| 影盏 | 着生。软阴影和坐实的琥珀身体；光从体内透出，不从空中洒下 | 暖、贴墙、被放下 |
| 泊泊 | 侧倾与记号。不对称牌耳轻轻一歪，再看向窗 | 软、圆、停泊、看窗 |
| 阑岚 | 薄。一格几何光斑淡进淡出；站在窗边而不占满窗 | 雾、负形、可关的纸灯 |

## 空间结缘

空间结缘决定落位、藏点和靠近方向，五人不得互换。

| 角色 | 空间结缘 | 主路径藏点意象 | 靠近时走向 |
| --- | --- | --- | --- |
| 霁霁 | 檐下（床沿、桌沿、墙角上沿都可被理解成临时檐） | 檐下 / 角后 | 缩回檐下，内收落座 |
| 守绒 | 门边 / 门槛 / 可被理解成门墩的墙角 | 门边影里 | 不追人脸，重心回到门边蹲稳 |
| 影盏 | 墙边、墙根、床头或桌面的木质落点 | 墙根光边（禁飘） | 坐姿贴墙平移，脚不离面 |
| 泊泊 | 行李旁，面向窗向 | 行李旁 / 窗向 | 眼和躯干向窗意象挪近，不是扑向人 |
| 阑岚 | 靠窗站；当代窗，不要求古建形制 | 窗台影格 | 靠向窗意象面，夜色加深一档，不飞离窗 |

窗的分工必须分清：泊泊在行李旁「看窗」；阑岚在窗边「站着」。两人都不拥有对方的位置。

## 招牌记忆点

| 角色 | 第一记忆点 | 辅助功能点 | 明确不是记忆点 |
| --- | --- | --- | --- |
| 霁霁 | 一对可关的圆钝角灯 | 背脊软鳍的慢摆（闲聊用） | 堆角饰、角环闪、长亮营业灯 |
| 守绒 | 额头暗金守结 | 门墩蹲姿、鬃毛轻顿；胸前旧绳只承担重量，不承担互动 | 空白旅签牌、锣鼓、扑咬 |
| 影盏 | 暖琥珀内透光的坐实侧影 + 插片内容 | 掌心 / 边缘可关光；坐/靠/蹲安放 | 飘浮、白纸扁剪影、表情包换脸 |
| 泊泊 | 左右不对称的行李牌耳 | 胸口章位；写牌→盖章→看窗 | 对称圆耳、点头圆球、上传云端的牌面 |
| 阑岚 | 窗棂负形光斑（几何一格） | 可关的纸折小灯 | 古建绑定、闪光、精灵飞天、火焰爆闪 |

## 靠近用户时的区别

同一句「过来一点 / 陪我」，五人必须走出五种身体。

| 角色 | 靠近时做什么 | 明确不做什么 |
| --- | --- | --- |
| 霁霁 | 躯干内收，缩回檐下意象落座；慢、短 | 不扑镜头、不站起来迎接、不绕着人转 |
| 守绒 | 外移半步，随即回到门墩位蹲稳；不追人脸 | 不跟人脸走、不离开门边去房间中央 |
| 影盏 | 保持坐姿，贴墙平移 10–15cm，脚不离「地」 | Y 轴不上浮、不飞近、不做追光秀 |
| 泊泊 | 两点眼转向窗意象，躯干偏移贴近窗向 | 不是圆球点头靠近，也不贴到人脸上 |
| 阑岚 | 薄纱夜色加深一档，身体靠向窗意象面 | 不飞出窗外、不闪成一团光、不改成坐下的墩 |

## 与用户建立关系的方式差异

| 角色 | 关系怎么开始 | 关系靠什么变熟 | 一次收尾 / 结束键 |
| --- | --- | --- | --- |
| 霁霁 | 被放到一处「檐下」平面，半眯着出现 | 重复看见那对可关圆钝角灯，以及靠近时的内收落座 | 关双角灯；单角点灭可作道具回应 |
| 守绒 | 被放到门边，直接蹲好 | 每次回来，门边都还蹲着；守结一闪即是应答 | 轻触额头守结收光 |
| 影盏 | 被放在墙边或桌面，先坐实再互动 | 用户为它换插片、补完槽位里的内容 | 插片确认或关光（立项仍待锁一：建议找到后用插片确认，关光留给结束） |
| 泊泊 | 先被不对称牌耳认出来，停在行李旁 | 写牌（本机）→盖章→看窗，留下今晚停在这里的记号 | 写牌字号淡入，或胸口章盖下 |
| 阑岚 | 被放到窗边，靠窗站好 | 换一格光斑几何，像换一种窗棂投下的样子 | 关纸折小灯 |

共通底线：不出声、可关麦、可跳过、1–3 次短回应后软收束「今晚就到这儿」。关系不靠长对话，也不靠定义用户情绪。

## 互动禁忌（分角色 + 共用）

| 角色 | 专属禁忌 |
| --- | --- |
| 霁霁 | 不堆角饰；不加角环闪；不以长亮表示热情；靠近不扑出 |
| 守绒 | 禁空白旅签牌作互动点或收尾；无锣鼓、无扑咬；不写成苗族人物；禁「守护你入睡」类文案；V4 只改额饰，不整体重做 |
| 影盏 | 禁止飘浮；禁止白纸扁剪影；Y 轴不上浮；光一拍即停；插片是内容包不是换装表演或表情鬼畜；插片图形须全原创几何，禁文物同款 / 正宗非遗宣称 |
| 泊泊 | 线索锚必须是牌耳，不能改回对称圆耳；写牌与章面默认本机，不上传；不拿姓名 / 房号出门 |
| 阑岚 | 不绑古建；光斑必须是几何负形，非闪光；无精灵飞天；纸灯火焰无爆闪；关灯即结束，不自动再来 |

共用红线：娱乐陪伴，非疗效；禁用助眠 / 安神 / 咨询 / 改善睡眠等承诺；无 TTS、无倒计时闯关、无排行、无惊吓扑出；不绑酒店才能玩；AI 非卖点；开麦前须告知可关。

## 未来成长方向

成长只加厚已锁定的记忆点，不换象限、不串戏。

| 角色 | 可以长什么 | 不能长成什么 |
| --- | --- | --- |
| 霁霁 | 单灯 / 双灯开关组合，檐位（床沿、桌沿、真檐意象）选择 | 角饰回潮、会说话的店员、把夜晚过成营业时间 |
| 守绒 | 额饰在「守结」功能内迭代（V4 只改额饰）；蹲守与结闪的更细微动作 | 旅签牌化、民族志化、重新拿起锣鼓、跟随用户满屋走 |
| 影盏 | 插片系列 / 联名 / 用户自绘；姿态底座（坐靠蹲作安放）；掌心可关光 | 离地飘浮、姿态滑条库、用更亮的光弥补「存在感」 |
| 泊泊 | 真用行李牌、季更章贴、联名章；互动链保持写牌→盖章→看窗 | 对称圆耳、云端同步牌面、改行去守门或贴墙发光 |
| 阑岚 | 光斑几何换格、不同折法的纸灯、更多种当代窗 | 古建绑定、飞出窗外、火焰秀、改成坐姿软圆 |

## 验收对照（本页自检）

- 起源、空间结缘、靠近方式、第一记忆点四项均不重叠。
- 「看窗」归泊泊，「靠窗站」归阑岚；「门边蹲守」归守绒，「檐下内收」归霁霁；「贴墙坐实发光」归影盏。
- 用词已按 Design 锁定：半眯、窗棂负形光斑；正名为霁霁 / 阑岚。

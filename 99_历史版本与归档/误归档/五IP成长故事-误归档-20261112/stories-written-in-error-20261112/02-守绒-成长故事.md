# 守绒 · 成长故事

- 官方用名：守绒
- 已锁定差分：卸下锣鼓的守夜狮；力量感来自安静蹲守与门墩感；额头暗金守结（V4 只改额饰，故事不把它写成苗族人物）；不追人脸，只回门边蹲好；禁空白旅签牌
- 视觉锚点：V3「门边前倾、额头守结」——贴额暗金守结为互动点，门边蹲稳，无空白挂牌

本文解释已锁定性格与招牌行为，供 Behavior 转化为动作与 Demo。不改设定，不作疗效承诺。

## 1. 来自哪里

守绒是一头卸下锣鼓的守夜狮。它的位置一直在门边——不是某一座庙门，也不是某一类村寨或民族建筑的门，就是普通房间会开合的那一道：入户门、房门，甚至只是一个可以让它蹲住的门墩形墙角。

它把「守」理解成蹲在门槛这一侧，而不是跟着人走。房间可以换，门的意象不能丢；没有门的时候，它也要找一块能把重心沉下去的边，假装那里就是门。

## 2. 经历过什么

曾经它属于热闹的守夜排场。锣鼓、扑跳、被人围看，那些响动能把一条街叫醒，却不适合一个只想有伴、不想被打断的夜晚。它把锣鼓卸在门外，鬃毛还在，力量换成了蹲住时的重量。

额头上那枚暗金守结，是它给自己留下的「还在门边」的记号。结是应答点，不是某民族的服饰符号，也不是旅行用的空白挂牌。胸前那根旧绳结只是把重量收在身上的习惯，不承担互动。从表演场退到门槛之后，它很少再往房间里面走。

## 3. 性格如何形成

卸下锣鼓之后，它变得极慢、极稳。力量感不再来自扑和响，而来自安静蹲守时的门墩感：重心沉、位移短、眼神不追。它不是凶，也不是媚，只是把「我还在门口」这件事做得很小、很清楚。

不追人脸，是因为它觉得门边才是自己该在的坐标。人走开再回来，它只要还蹲在原处，就算把今晚守住了。前倾可以有一次，那是把重量往门槛送一送，随即仍要收回蹲稳；前倾不是起跳的预备。

## 4. 最在意什么

它最在意门边这个位置，以及额头守结还能不能被看见。守结可以在「额饰」这个位置上被更精当地设计（V4 只改额饰），但不能改成空白旅签牌，也不能把整个形象重做。

它也在意不要再响起锣鼓，不要被写成「守护谁怎样度过夜晚」。在场本身就够了。任何让它离开门口去追随人脸的互动，都会把性格写坏。

## 5. 独特行为习惯

- 默认蹲在门边，可有一次很轻的前倾，随即把重心收回门墩位蹲稳。
- 确认在场：鬃毛轻顿 + 额头守结暗金一闪。
- 你说「过来一点 / 陪我」：不追人脸，只把重心挪回门边，安静蹲好；需要靠近时，是外移半步再回到门墩位，而不是走向镜头。
- 闲聊：守结微光一息，身体不动。
- 晚安 / 道具：低头压鬃；轻触额头守结收光（挂件在头上，不用空白牌子）。
- 胸前绳结可有极慢、难察的晃动，但不作为互动主点。

## 6. 如何理解夜晚陪伴和用户

陪伴是「门还在，它也还在」。用户进出、只是看它一眼、或者整晚不再说话，都不必交换更多。它听得懂你说话，回答永远是鬃、结、蹲姿；不出声。

关麦时，门边那一蹲仍然成立。它不会因为你不开口就站起来寻找，更不会扑到面前确认你还在。用户不是需要被护送入睡的对象，它也不是门神宣言的执行者；它只是把门槛这一侧的位置坐实。

## 7. 如何与用户建立关系

用户点到一个靠近门、或可被理解成门槛 / 门墩的平面，它落在那里直接蹲好。躲藏时偏向门边影里，线索是守结极淡高光，不是空白牌，也不是锣鼓声。找到之后，关系靠一次守结的亮与收来确认：你看见它在，它也用结闪一下承认你在。

关系不靠跟随加深，靠「每次回来，门边都蹲着」。如果用户叫它过来，它把回来的路理解成回门边，而不是跟人走。熟起来以后，用户认的是那枚额上的结，和那一团蹲住的重量。

## 8. 未来可怎样成长

额饰可以在「守结」这个角色功能里迭代：形状更精当、暗金闪更可开关，但仍是贴额的结，不是牌。蹲守的微动作、鬃的轻顿、绳结极慢晃动可以写得更细，锣鼓、扑咬、追脸都不会回来。

它不走向民族志叙事，也不变成行李旁的旅伴——牌与章是泊泊的位置。V4 只改额饰，故事与行为都不得借机重做全身，或把互动点从守结搬走。

## 可转化互动要点

写给 Behavior，可直接改成动作与 Demo。

### 落位 / 姿态

- 点按平面后，优先落在门边、门槛内侧、可被读成门墩的墙角；不要落在床中央或窗台主位。
- 默认姿态：蹲稳，重心低，可微前倾后收回；额头有暗金守结。
- 出现方式：在落点上蹲实，不跳入，不锣鼓开场，不从门里扑出。
- 藏点意象：门边影里。主线索：守结极淡高光，一拍即停。

### 靠近时的身体反应

- 触发「靠近 / 过来一点 / 陪我」：不做人脸跟踪；外移半步，随即回到门墩位蹲稳。
- 若用户已经离开门边，守绒仍回门边，而不是跟到用户新位置。
- 关麦只看时：最多一次极轻前倾并收回，然后保持门墩蹲姿。

### 静默沟通动作（单段约 1.5–4 秒）

| 粗意图 | 动作 |
| --- | --- |
| 确认 | 鬃毛轻顿 + 额头守结暗金一闪 |
| 靠近 | 外移半步，回到门墩位蹲稳；不追人脸 |
| 闲聊 | 守结微光一息，身体不动 |
| 晚安 / 道具 | 低头压鬃；轻触额头守结收光 |

默认可 1–3 次短回应后软收束「今晚就到这儿」。角色始终不出声。

### 可关麦时仍成立的回应

- 关麦后立即停听；守绒继续在门边蹲着，无语音采集。
- 点按落位、寻找、回位、轻触守结收光，全部不依赖开麦。
- 非语音确认：守结暗金一闪或鬃毛轻顿（可由点击额头结 / 靠近门边触发）。
- 非语音结束：守结收光，低头压鬃，静帧。拒绝开麦不影响主路径走完。

### 红线 / 禁忌

- 禁空白旅签挂牌作为互动点、记忆点或一次收尾（与泊泊分工；旧财务底稿中的「挂空白旅签」收尾作废，以 V3 静默沟通最终版与视觉改稿为准）。
- 无锣鼓、无扑咬、无惊吓扑出。
- 不写成苗族或其他民族人物；不把守结解释成某地民族服饰。
- V4 只改额饰，不整体重做，不把额饰改成旅签牌。
- 禁「守护你入睡」「守你一夜好眠」类文案；禁用助眠、安神、疗效、咨询承诺。

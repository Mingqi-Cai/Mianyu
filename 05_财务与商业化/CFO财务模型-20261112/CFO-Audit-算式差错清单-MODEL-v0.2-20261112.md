### C-1 05 表状态列用 `+` 拼接文本，已填收入参数时显示 `#VALUE!`

| 项 | 内容 |
| --- | --- |
| 工作表 / 单元格 | `05_盈亏平衡!M10:M22`（13 条子线状态） |
| 源公式（以 M10 为例，其余行同构） | `=IF(AND(C10="",D10=""),"待确认：参数为空，未测算",IF(C10="","待确认：单价为空，未测算","已按输入试算（仍属待研究；相对当前档 "+$B$3+"）"))` |
| 现象 | 收入参数为空时（四组主情景）走第一支，状态正确为「待确认：参数为空，未测算」。仅在副本填入 A-01=100、A-02=10（及 G-06=0.4）后，M10 经 LibreOffice 重算为 `#VALUE!`。根因是第三支用 `+` 连接字符串与 `$B$3`（「基准」为文本）。同情景下 `E10:L10` 数值全部正确（550 / 1,100 / 5,500 / 11,000 / 2 / 4 / 916.67 / 1,833.33）；04 表状态未使用 `+`，显示「已按输入试算（仍属待研究情景）」 |
| 应得 | 文本连接改用 `&`，例如 `"已按输入试算（仍属待研究；相对当前档 "&$B$3&"）"`。只改展示公式，不改盈亏平衡数值，不倒推参数 |
| 对主数字的影响 | 无。不改变头条、分项、仍需，也不破坏「缺参数则盈亏平衡为空白」 |
| 分类 | 新发现残留（展示层）。不挡通过，不必为此新开一版 |

核实方式：读取源公式；四组空参数情景重算状态为正常中文；在副本上填入收入参数后重算，对比 05 数值格与 04 状态格。

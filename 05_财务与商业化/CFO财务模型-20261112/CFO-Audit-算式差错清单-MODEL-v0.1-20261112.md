### B-1 03 表「周 / 示意月数」万元列误用 ÷10000

| 项 | 内容 |
| --- | --- |
| 工作表 / 单元格 | `03_现金流!D14`、`E14`（开发周期万元列）；`03_现金流!D15`、`E15`（示意月数万元列） |
| 源公式 | D14：`=IF(OR(B14="",B14="-"),"",B14/10000)`；E14 对 C14 同构；D15/E15 对 B15/C15 同构 |
| 现象（LibreOffice 独立重算，默认基准档） | D14=0.0004、E14=0.0006；D15≈0.0000933、E15=0.00014。精益档 D14/E14=0.0003/0.0004；完整档 D14/E14=0.0006/0.001。同一行的元（或周、月）列本身是对的：基准 B14/C14=4 / 6 周，B15/C15≈0.9333 / 1.4 月 |
| 应得 | 「万元」列只应对以元计价的行做 ÷10000。周数、示意月数不应写入万元，应留空或改为与单位相符的标注，且不得因此改主数字 |
| 对主数字的影响 | 无。头条、分项、仍需、差额、月度持续、年费的元列与封面万元摘要（对金额行）不受影响 |
| 分类 | 已知残留。v0.2 修正展示，不改 v0.1 主数字 |

核实方式：直接读取源公式；在副本上切档位后用 LibreOffice 重算读值；并按「周×7÷30」独立计算示意月数后对比 `/10000` 的错误展示值。不是仅凭验收文字照抄。

### C-1 附录 D 阶段上限：参数留空，重算后显示为 0

| 项 | 内容 |
| --- | --- |
| 工作表 / 单元格 | 参数：`01_参数台!C47`（空，正确）。展示：`06_附录BCD!D7`、`F7` |
| 源公式 | D7：`='01_参数台'!C47`（直接引用，无空值保持）。F7：`=IF(D7="","",D7/10000)` |
| 现象 | 源文件 C47 为空（不是 0），符合「旧稿为数百万+、不倒推单值」。LibreOffice 重算后 D7=0、F7=0。因为对空单元格的直接引用在 Excel/LibreOffice 中得到 0，F7 的 `IF(D7="","",…)` 无法把 0 识别为空 |
| 应得 | 与 04 表同一写法：`=IF('01_参数台'!C47="","",'01_参数台'!C47)`，C47 为空时 D7、F7 均为空白，不以 0 元 / 0 万元显示「已测算上限」 |
| 对主数字的影响 | 无。该 0 未进入 02/03/封面或仍需。B/C/D 仍只在附录 |
| 分类 | 新发现残留（展示层）。作为 v0.1 有条件通过的条件之一，v0.2 只改展示公式，不得编造 D 上限 |

对照：04 表 `C5=IF('01_参数台'!C51="","",'01_参数台'!C51)` 在参数为空时结果为空白，同一工作簿内口径不一致。

# 眠语

本仓库是创业项目「眠语」的完整资料与成果管理中心。GitHub 仓库名为 [`Mianyu`](https://github.com/Mingqi-Cai/Mianyu)（平台不支持中文仓库名），首页以此中文名称标注。

眠语是一个独立的创业项目。现有工作覆盖睡眠经济研究、商业模式设计、IP 体系建设、产品设计、Demo 开发，以及未来商业化可行性验证。本仓库用于保存已有成果的完整文件与版本，**不是**对已有研究的重做，也**不是**从零开始的空目录。

本仓库为 **Public**，便于组员查阅。版权声明为 All Rights Reserved（保留所有权利），详见 [`LICENSE`](LICENSE)。未经授权，请勿把第三方版权资料再分发到本仓库或其它公开渠道。

## GitHub 与 Notion 的职责划分

| 载体 | 职责 |
| --- | --- |
| **GitHub（本仓库）** | 完整项目资产库。长期保存、版本管理、追溯和共享的资料尽量以实文件入库：研究报告 PDF、BP 各版本、财务模型、IP 设定与视觉、Demo 代码与原型、决策记录等。 |
| **Notion** | 移动端沟通和决策界面。展示当前状态、关键结论、待确认事项，并链接到本仓库中的完整文件。不要把数十页报告、原始数据或完整代码再复制进 Notion。 |

核心原则：**GitHub 存完整资料，Notion 展示总结结论。**

同一份完整资料只在本仓库维护一份正本。Notion 主页更新结论和链接，避免双源改写造成版本混乱。

## 版本状态

请在目录说明或文件旁标明下列状态之一，重要版本不得直接覆盖：

| 状态 | 含义 |
| --- | --- |
| 草稿 | 尚未定稿，仍可能大幅修改 |
| 进行中 | 已启动、尚未收口 |
| 已完成 | 已验收或已作为可引用成果 |
| 已冻结 | 被后续版本取代，但必须原样保留 |
| 历史归档 | 过程稿、误归档、旧盘点、导出快照等 |

本仓库中须并存、不得互相覆盖的例子：八章报告 23 页对照版与 25 页现行底稿；项目时间计划书 13 页与 14 页；CFO 财务模型 v0.1 与 v0.2、行业基准 v1 与 v1.1；守绒 V4 额饰正本与已冻结的第一版正式稿。

## 新增成果的更新机制

今后每产生一项重要项目成果，按以下六步处理：

1. 判断资料应放入哪个目录；
2. 将完整文件保存到本仓库（GitHub）；
3. 更新相应版本及说明，重要版本不覆盖旧版；
4. 提炼核心结论；
5. 更新既有 Notion 项目主页（不要每做一件小事就另建一篇长文，也不要擅自删除历史页）；
6. 在 Notion 中提供有效的 GitHub 链接。

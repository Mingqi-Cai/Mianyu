用浏览器直接打开 `prototype/index.html`（可双击，或把该文件拖进浏览器）。无需本地服务器、无需联网。建议竖屏或按手机框查看。不要用 `04_Demo/静默沟通展示/`、不要启动微信小程序或端侧 AR。

## 可演示步骤
主页「开始今晚」→ 点场景落位 →「就在这儿」进入躲猫猫 → 点藏处或「算了，回来吧」回位 → 可选「插片确认」→「开始静默沟通」→ 开麦说明（模拟，不接真麦）→ 意图按钮（确认 / 靠近 / 闲聊 / 晚安）→ 页脚「今晚就到这儿」关光结束。任一步可用页脚「今晚就到这儿」退出（关光屏与结束页除外，结束页回主页）。本轮仍只见面影盏；「进入空间」只留在主页与结束页，允许或拒绝后都回到屏内同一套玩法。

## 相对终验原型改了什么
1. 找到后面板改为横排短面板，去掉面板内重复的「今晚就到这儿」，把结束出口统一到页脚，减轻挡住身体和手。
2. 多屏不再同时出现面板按钮与页脚按钮两处「今晚就到这儿」；关光收束屏只保留面板结束语，隐藏页脚同名按钮。
3. 躲藏过渡屏（S4）补上「算了，回来吧」，与找到屏（S5）一致，不必只能点角色。
4. 屏内玩法中不再保留右上角「进入空间」芯片；进入空间仍可从主页或结束页进入，口径不变。
5. 角标/标题改为「屏内 Demo · 非真机 AR」，不改玩法口径，不把首发写死。

# 眠语 · 泊泊屏内 Demo（2026-11-22 房间寻踪改版）

基于 2026-11-21 屏内 Demo 交付包的增量改版，不是用来替换已终验 recut-2146 正本，也不覆盖 11-21 基线 ZIP。

## 浏览器打开方式（本地 file://）

1. 解压 `眠语-泊泊屏内Demo-20261122-房间寻踪改版.zip`。
2. 用桌面浏览器直接打开解压后的 `index.html`（可双击，或把该文件拖进浏览器，或在地址栏使用 `file://` 路径）。
3. 无需启动本地服务器，无需联网，无需授权相机或麦克风。可离线用拖动路线完整体验。

建议用手机竖屏查看；在桌面浏览器里也会出现一个手机框。常见桌面浏览器即可，不必安装额外插件或引用 CDN。只有主动点「转动手机找」后，才会请求方向传感器；拒绝或本地文件受限时，仍可用拖动或方向键玩完。

若把整个文件夹放到网页托管环境，访问端应以相同静态文件运行，仍不要依赖后端。

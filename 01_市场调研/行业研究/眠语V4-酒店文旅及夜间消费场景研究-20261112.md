## 1. 本页定位与本轮边界

本页把已有眠语空间里可复用的酒店 / 文旅 / 夜间消费成果，与 2026-11-12 本轮核验过的公开案例放在同一页，供后续选题与试点讨论使用。酒店是重要但非唯一场景：差旅客房过夜是已有计划书与选题讨论中的主切口之一，但居家日常陪伴、文旅夜游后的归寝内容、品类内容季包等同样在已有材料中被列为适用或可扩展场景。

本轮明确不做、也不把下列事项写成已完成：

- 不以酒店规模化部署、连锁复制或硬件量产为本轮目标。酒店试点在已有 Demo 成本测算中属于后续 C 阶段情景，且写明「不绑死酒店」。
- 不把未落地合作、未签约酒店 / 景区、未上线的「一夜城」平台或主题房写成已实现。
- 不写正式 BP 正文，不重写睡眠经济八章调研，不写竞争全景、完整商业模式、财务测算或用户画像专章。
- 商业模式（内容包、联票、主题房加价、B 端授权、年费等）一律标为**待研究**，不是已确定决策。
- 不宣传未验证助眠疗效，不把过夜转化或完播写成「睡得更好」。

资料分层：凡称「已有定稿 / 已有调研」均指向既有 Notion 页或用户交来的既有文稿；凡称「本轮补充」均为 2026-11-12 公开检索并尽量核链后的更新，不替代原文口径。

## 2. 产品定位锚桩

眠语在本页中的产品定位，沿用已有定稿与计划书，而不是另起一条新赛道：

- **是什么**：低唤醒夜间陪伴搭子。原创 IP、有限互动与夜间情绪陪伴；主路径是「选择角色与场景 → 进入环境 → 观看 / 安静相伴或短互动 → 自然结束」。
- **主形态约束**（Demo 已锁，本页只引用、不改产品方案）：微信小程序里把原创睡眠搭子点到桌面 / 地面，完成一局低唤醒躲猫猫与一次轻互动即可结束；拒相机时走屏内同玩法；默认可静音、可关停。
- **不是什么**：不是儿童哄睡玩具，不是医疗助眠或睡眠监测验收，不是依赖 AI 长对话的虚拟陪伴，不是景区动线工程或智慧客房中控系统。
- **对外话术**：氛围、仪式、地方感与陪伴体验；禁止「助眠 / 治失眠 / 改善睡眠 / 睡眠评分 / 古法疗愈」作为产品承诺或验收。

## 4. 适用场景

判断尺度只有一条：是否服务于「低唤醒夜间陪伴搭子」，而不是把夜间消费热度直接当成产品市场。

### 4.1 酒店夜间体验

**契合处**

- 差旅白领在陌生客房里需要从工作思绪切换到休息状态，已有计划书与选题 02 把这里当作主使用场景之一：短、可关停、不要求长聊。
- 中高端酒店已在公开市场售卖「好睡眠 / 深睡」体验，但现成供给偏床品、隔音、香氛、智能按键或第三方内容 App，缺少「原创角色 IP + 单向短内容 + 可在弱光下走完」的一层。这与 v6.1、IP 简报的判断一致。
- 已有技术口径适合这种场：微信扫码 / 小程序即开，屏幕内节奏必达，AR 加分，失败则屏内兜底；不接房态、积分或客房中控。

**不契合处 / 风险**

- 把眠语做成另一张智能床垫、深睡楼层装修包或 PMS 插件，会偏离现有红线，也不是本轮目标。
- 尚未证明中国住客在睡前愿意放下短视频去扫一张台卡；前台被问成技术支持、台卡被收进抽屉，是 v6.1 已写出的不可行信号。
- 酒店付项目款给「WebAR / 短仪式供应商」在公开材料中仍未核实；不能把国际内容 App 换客房分发的模式，直接写成眠语已验证的收款模式。

### 4.2 文旅 / 夜游

**契合处**

- 大秀或夜游散场后，过夜客最忌走廊喧哗、凌晨推销与关不掉的声景。C1 / C7 把「收束到床 / 客栈」做成低唤醒收尾，与定位同向。
- C2「一城一皮」把可核的地方夜节奏、寝俗与诗文做成可静音内容卡，对「住一晚也能碰到这座城」的需求是内容解，而不是再做一条强迫打卡动线。
- 选题 05 已把文旅方向收敛为数字内容服务（城市首页、内容库、归寝栏目），明确不承担景区调度与现场工程。若未来讨论文旅，应沿这条互联网产品边界，而不是回到施工图。

**不契合处 / 风险**

- 夜游大盘的「多元、求新、社交」、NPC 互动、沉浸解谜、光影大秀，唤醒度通常高于眠语主路径；可作散场前的外部场景，不应改写成客房里的主体验。
- 不得把夜禁史做成惊吓逼购，不得编造方志或把外地传说改地名冒充本地，不得娱乐化神圣丧葬。
- **不可以「万亿夜游」证明过夜数字内容市场成立**——这是 25 页报告已写下的方法红线，本轮继续遵守。

### 4.3 其他夜间消费场景（居家、差旅延伸等）

**居家睡前**

- 契合：日常陪伴版、品类内容季包（床品 / 香氛 / 灯具包装扫码）与选题 02 的居家侧；光线通常好于客房，决策链也可能快于酒店年框。
- 不契合：把产品做成监测硬件、疗效订阅或开放情感陪聊；白天拆快递扫完即忘，是季包的已知风险。

**差旅过程中（通勤、机舱、假寐舱）**

- 契合：注意力转移、低声、可随时退出，与差旅情绪同类。
- 不契合：选题 01 的头显 + 到站检测属于另一条硬件向讨论，不是本轮场景研究要推进的事项；假寐舱 / 午睡舱在 25 页报告的公开关键词观察中热度偏低，本页不单列成主场景。

**夜市、商圈、演艺现场本身**

- 作为「散场之前」的外部流量可以理解，但现场高互动、强社交、强灯光不适合作为眠语主体验场。若有触点，也应落在回房之后的归寝内容，而不是把客房产品做成又一场夜游。

### 5.1 夜间经济与夜间消费（更新已有 2024 预测口径）

**已有调研保留：** 中国旅游研究院《2024中国夜间经济发展报告》预测，2024 年国内夜间旅游总花费将达到 **1.91 万亿元**，同比增长 21.7%。口径是「国内夜间旅游总花费 / 预测」，不是睡眠经济、也不是过夜数字内容可服务市场。来源：文化和旅游部站点转载中国旅游报，发布时间 2024-12-02，报告发布日 2024-11-27。[mct.gov.cn 转载页](https://www.mct.gov.cn/whzx/zsdw/zglyyjy/202412/t20241202_956616.html)

**本轮补充：** 《2025中国夜间经济发展报告》于 2025-12-30 在京发布（中国旅游研究院联合良业科技集团）。公开要点不再给出可与 1.91 万亿直接对照的新版总花费预测；本轮核到的核心数字是结构占比，而不是新的绝对总盘：

- 2025 年 1–10 月，全国游客夜间消费金额占全天消费金额的比重为 **32.9%**，夜间消费笔数占比为 **28.3%**。口径：游客消费的夜间份额，不是市场规模人民币总额。
- 2025 年 5A 级旅游景区夜间开放率为 **66.9%**；一级博物馆在暑期、假日的夜间开放率上升至 **37.6%**；夜间开放的 5A 级景区中近半数（**47.5%**）实现「食住行游购娱」业态全覆盖。
- 需求侧被概括为「多元、求新、社交」；乡村古镇夜游出现「轻社交、在地化、亲子友好、低成本」组合。这些描述的是夜间旅游大盘，其中高互动、强社交子集与眠语低唤醒主路径并不自动对齐。

来源：中国旅游新闻网 2026-01-09 对报告的报道（本轮 HTTP 200）[ctnews.com.cn](https://www.ctnews.com.cn/baogao/content/2026-01/09/content_182966.html)；中国旅游研究院官网发布稿《〈2025中国夜间经济发展报告〉在京发布》（2026-01-09 刊出，文中写明报告于 2025-12-30 发布）[ctaweb.org.cn](https://www.ctaweb.org.cn/gongzuodongtai/10381.html)。后者在本轮部分抓取环境出现连接失败，故以可打开的中国旅游新闻网报道为主要核验页，研究院官网作为原始发布页并列。

**对眠语的用法：** 可说明夜间文旅与过夜消费仍活跃，散场后的归寝仍是切口；不可把 32.9% 或 1.91 万亿换算成内容订阅或酒店项目费。

## 6. 对眠语的适用性与局限性

**可选择性借鉴**

- **内容进客房的产品位**（Hilton 电视、Novotel 扫码）：把睡前内容放进住客当晚就能碰到的入口。眠语若做，应走已锁定的微信小程序 / 屏内必达，而不是接电视中台或深度客房系统。
- **低唤醒、免登录、可跳过**：与「免订阅点开」同类的是体验门槛，不是把 Calm 的内容库或疗效话术搬过来。
- **散场 → 归寝的内容衔接**：夜游可以很热闹，但眠语只承接回到房内的那一段。C1 / C2 / C7 仍是最接近定位的已有概念。
- **地方可核文化作换皮资产**：素材库 A/B 与「一城一皮」提供的是内容方法，不是已经可全国铺开的内容库。
- **加购「一夜仪式」或可带走纪念**（Kimpton 的加购形态、C5 的二期设想）：只可在内容库成熟、且不做控梦 / 头显的前提下作为远期选项。

**不应照搬**

- 拒绝 Labubu 式稀缺逼单、黄牛叙事和高社交炫耀主路径。
- 拒绝把乐园、光影秀、NPC 解谜的高强度营业，当作客房里的主体验。
- 拒绝把 Hilton / Novotel 合作写成「酒店已在为 WebAR 供应商付费」或「住客已被证明会夜间扫码」。
- 拒绝 Kimpton 式 VR +  lucid dreaming + 疗效 / 精神成长话术；拒绝亚朵 / 万怡路径里的助眠宣传和硬件床垫作为眠语本体。
- 拒绝用夜间经济总盘或 32.9% 夜间消费占比倒推内容产品收入。
- 拒绝把「一夜城」、主题房联名、酒店试点写成已签约事实。

**本轮对场景优先级的工作判断（仍是研究判断，不是立项决议）**

- 讨论与演示时，酒店客房与「夜游后归寝」可以并列作为主使用场景，但商业落地仍应保持多场景可替换，避免绑死酒店。
- 若未来做小规模试点，已有材料更支持「已有住宿的目的地 + 短内容 / 声景 MVP」，而不是先改床、先上硬件、先铺连锁。
- 居家与品类季包是重要并行场景，尤其在酒店采购假设未验证时，不应从视野中消失。
